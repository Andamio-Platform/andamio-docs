## What to Expect

The Andamio tokenomics model covers:

- **Participation Rewards** — How contributors, students, and project participants earn value
- **Protocol Fees** — Service fee structure for course creation, access tokens, and project operations
- **Treasury Design** — How instance and protocol treasuries work
- **Token Utility** — The role of on-chain tokens in credentialing, governance, and access

For current protocol fee information, see [Cost Estimation](/docs/protocol/v2/cost-estimation).
