## Andamio Pioneer Tools

1. We use Discord for daily communication. [Join the Andamio Network Discord server](https://discord.gg/abBbsGZpZ5) to connect with other pioneers and stay up to date.
2. We use Github for project management and collaboration. On Discord or in a Live Coding session, share your Github handle, and we will add you to the Andamio Pioneers team on Github. Then, you will be able to access the [Andamio T3 App Template](https://github.com/Andamio-Platform/andamio-app-v2).
3. We use Google Meet for Live Coding meetings. We record each meeting and will share both the video links and the meeting transcripts in the [Live Coding Archive](./live-coding/archive). The meeting link will be shared via Discord, and we will have a public calendar soon.

## Andamio T3 App Template

Andamio V2 is live on Cardano mainnet. The Course and Project systems are fully operational. Clone the [Andamio T3 App Template](https://github.com/Andamio-Platform/andamio-app-v2) to get started.

### Environment Variables

To use the template locally, create a `.env` file in the root of the project. You can use `.env.example` as a template:

```
# Andamio API Gateway (unified V2 API)
NEXT_PUBLIC_ANDAMIO_GATEWAY_URL="https://dev.api.andamio.io"

# Andamio API Key (request via the Gateway)
ANDAMIO_API_KEY="your-api-key"

# Cardano Network
NEXT_PUBLIC_CARDANO_NETWORK="preprod"
```

## Andamio API Gateway

All APIs are unified behind the [Andamio API Gateway](https://dev.api.andamio.io/api/v1/docs/index.html). This single endpoint handles authentication, data queries, and transaction building.
