# Andamio Pioneers

A program for builders exploring the Andamio protocol. Launched January 2026.

## What is Pioneers?

Pioneers collaborate with the Andamio team to build in public, test new features, and shape the platform. The program itself runs on Andamio — you'll learn the protocol by using it.

## Join the Program

1. **[Join Discord](https://discord.gg/wfGrgJJheS)** — daily communication and session announcements
2. **[Set up your dev environment](/docs/getting-started)** — clone the app template, get an API key
3. **[Mint an Access Token](https://preprod.app.andamio.io)** — your on-chain identity
4. **Share your GitHub handle** in Discord to get added to the Pioneers team

## Live Coding Sessions

Weekly sessions on Wednesdays at **14:00 UTC** and **20:00 UTC**. We build in public, answer questions, and assign challenges.

- [Current Agenda](./live-coding/agenda) — what we're working on now

## Philosophy

The first Andamio prototypes were built at Gimbalabs in 2021 — a place where people gathered to tinker with Cardano and explore questions both technical and social.

Pioneers follows the same pattern: investigate how Andamio works, what can be built upon it, and what it means now that we have these tools.
