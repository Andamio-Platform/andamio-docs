Welcome to Andamio Pioneers! This program will officially launch in January, 2026. We are currently testing some systems and building with friends. This section of the documentation will evolve as we start to use it.

## Andamio V2: January 2026

Andamio V2 is a significant update the Andamio platform, including comprehensive on-chain and off-chain improvements. It will launch on Cardano Mainnet in January, 2026. We are currently testing Andamio V2 on Cardano Preprod. Early pioneers are invited to join us in testing the new platform.

## Building in Public

In 2026, Andamio will be building in public all the time. 

The very first prototypes for what would become Andamio were built at Gimbalabs in 2021. At that time, Gimbalabs was a place where people gathered to tinker with a new technology called Cardano, and to explore questions that were both technical and social, like "suppose we could build a concert ticketing platform on Cardano. How would it work, techinically? And what would it mean, socially, for a music fan, that their ticket is an NFT on the blockchain?"

In 2026, we are following these patterns, this time for a new technology called Andamio. We will investigate how it works, what can be built upon it, and what it might mean, now that we have these tools.

## Invitation for Andamio Pioneers

Andamio Pioneers are invited to collaborate with the Andamio team as we build in public, to take on leadership roles in building with Andamio, and to have input into how the Pioneers program evolves.
