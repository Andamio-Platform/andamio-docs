This page tracks our ongoing V2 protocol exploration sessions. We're building documentation by examining real transactions, verifying costs, and experimenting with on-chain data reconstruction.

All 8 course system transactions have been parsed and costs verified against actual wallet deltas.

**Single Credential Loop Cost:** Student ~1.11 ADA + Teacher ~0.21 ADA = **~1.32 ADA total**

**Key Learning:** UTxO recycling significantly reduces actual costs. The index linked list reuses ADA from spent nodes, so wallet delta is less than sum of new UTxO deposits.

**Process:**
1. Execute transaction on preprod
2. Screenshot wallet delta
3. Compare against documented cost
4. Update docs if inconsistent
5. Document the UTxO flow (spent vs created)

See [V2 Cost Estimation](/docs/protocol/v2/cost-estimation) for current cost documentation.
