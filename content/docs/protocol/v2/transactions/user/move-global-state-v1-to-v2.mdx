# Move Global State V1 to V2 Transaction

## Overview

This special migration transaction allows users to upgrade their global state from protocol version 1 to version 2. This one-time migration preserves user data while enabling access to new V2 features.

## Protocol Description

The migration transaction carefully transfers user state from the V1 format to the enhanced V2 structure. It preserves all existing user data, tokens, and progress while upgrading the state format to support new V2 capabilities. Users must hold valid V1 state tokens to execute this migration.
