# General Transactions

General transactions for protocol participation.

## Transaction Overview

| Transaction | Description | Wallet Delta |
|------------|-------------|--------------|
| [Mint Access Token](./mint-access-token) | Join the protocol | ~7.9 ADA |

## Notes

- Mint Access Token is the **entry point** for all protocol participation
- The alias must be unique across the entire protocol
- 5 ADA service fee goes to the protocol treasury
- Access tokens are required for all subsequent transactions
