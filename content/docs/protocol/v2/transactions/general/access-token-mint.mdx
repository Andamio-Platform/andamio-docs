# Access Token Mint Transaction (V2)

## Overview

This transaction allows any user to mint access tokens (100at and 222at) required for participating in the Andamio protocol. These tokens serve as the entry point for all protocol interactions.

## Protocol Description

The V2 access token minting process is streamlined for better user experience. Users can mint both the basic access token (100at) and the alias token (222at) in a single transaction, providing them with the necessary tokens to interact with courses, projects, and other protocol features.
