# Register Local State Transaction (V2)

## Overview

This transaction allows users to register their local state with the global protocol registry. This registration is essential for participating in courses and projects within the Andamio ecosystem.

## Protocol Description

The V2 registration process creates a link between a user's local state and the global protocol state. This enables the protocol to track user progress, validate permissions, and maintain a consistent view of all participants across the platform.
