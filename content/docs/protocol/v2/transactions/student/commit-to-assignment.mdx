# Commit to Assignment Transaction (V2)

## Overview

This transaction enables students to submit completed assignments for review. It records the submission timestamp and prepares the assignment for instructor evaluation.

## Protocol Description

The V2 assignment commit process includes enhanced validation and metadata storage. Students submit their work by committing to an assignment, which updates their course progress, triggers the review process, and maintains an immutable record of their submission on-chain.
