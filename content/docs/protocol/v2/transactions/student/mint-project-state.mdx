# Mint Project State Transaction (V2)

## Overview

This transaction allows students to mint a project state token when starting a course-related project. This establishes their participation and tracks their progress through project-based learning.

## Protocol Description

The V2 student project state minting integrates with the course system. Students must be enrolled in a course to mint project state tokens, which then track their progress through course assignments and projects. The token serves as proof of enrollment and enables submission tracking.
