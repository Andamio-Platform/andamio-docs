# Create Course

Admin creates a new course with initial teachers.

## API Endpoint

```
POST /tx/v2/admin/course/create
```

## Cost Breakdown

| Component | Amount |
|-----------|--------|
| Transaction Fee | ~0.55 ADA |
| Service Fee | 25 ADA |
| UTxO Deposits | ~19.74 ADA |
| **Total Wallet Delta** | **~45.3 ADA** |

The high UTxO deposit includes ~17 ADA for the LocalStateToken which contains an embedded script reference (the course validator).

## Request Body

```json
{
  "walletData": {
    "usedAddresses": ["addr_test1..."],
    "changeAddress": "addr_test1..."
  },
  "alias": "james",
  "teachers": ["james", "teacher2"]
}
```

## Transaction Pattern

**Mint and Create** - Mints 3 tokens and creates 3 new script UTxOs.

## Inputs

| ID | Type | Description |
|----|------|-------------|
| admin_global_state | script | Admin's global state (authorization) |
| admin_wallet | wallet | Admin wallet for fees/collateral |

## Outputs

| ID | Type | Validator | Value | Description |
|----|------|-----------|-------|-------------|
| admin_access_token | wallet | - | ~1.15 ADA + access token | Admin retains access token |
| local_state_nft | script | local-state-nft-validator | ~1.24 ADA + LocalStateNFT | Course registration NFT |
| local_state_token | script | local-state-token-validator | ~17.13 ADA + LocalStateToken | Course state with embedded validator |
| course_governance | script | course-governance-validator | ~1.31 ADA + governance token | Teacher list management |
| treasury_payment | wallet | - | 25 ADA | Service fee to instance treasury |

## Minting Operations

| Policy | Token | Description |
|--------|-------|-------------|
| local-state-token-policy | LocalStateToken | Course state token |
| course-governance-policy | \<courseId\> | Governance token (name = courseId) |
| local-state-nft-policy | LocalStateNFT | Course NFT (policy ID = courseId) |

## Key Design Features

- **courseId = LocalStateNFT policy ID** - The course identifier IS the minting policy that creates the LocalStateNFT
- **Embedded script_ref** - The LocalStateToken UTxO contains the course validator as a script reference (~17 ADA deposit)
- **Governance token naming** - The governance token is named after the courseId it governs

## Observers

- **course-observer** - Validates course creation via withdraw-0 pattern
