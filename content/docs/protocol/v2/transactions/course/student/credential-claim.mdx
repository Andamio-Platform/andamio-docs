# Claim Credential

Student claims their credential by burning the course state token after completing assignments. The credential hash is stored permanently in the student's global state.

## API Endpoint

```
POST /tx/v2/student/course/credential/claim
```

## Cost Breakdown

| Component | Amount |
|-----------|--------|
| Transaction Fee | ~0.35 ADA |
| Deposit Refund | ~-1.38 ADA |
| Service Fee | 0 ADA |
| **Total Wallet Delta** | **-1.03 ADA** (refund!) |

The student **gains** ADA because the burned course state UTxO releases its locked deposit.

## Request Body

```json
{
  "walletData": {
    "usedAddresses": ["addr_test1..."],
    "changeAddress": "addr_test1..."
  },
  "alias": "student_001",
  "courseId": "23a6bbce3a8deca8985764e847594f6956c9dc643e3f6c8efdba04e4"
}
```

## Transaction Pattern

**Burn and Update** - Burns course state token, updates global state with credential hash.

## Inputs

| ID | Type | Validator | Description |
|----|------|-----------|-------------|
| student_course_state | script | course-state-validator | Student's course state (burned) |
| student_access_token | wallet | - | Student's access token for auth |
| student_global_state | script | global-state-v2 | Student's global state (spent to update) |
| student_wallet | wallet | - | Student wallet for fees |

## Outputs

| ID | Type | Validator | Value | Description |
|----|------|-----------|-------|-------------|
| student_access_token_return | wallet | - | ~1.17 ADA + access token | Student retains access token |
| global_state_updated | script | global-state-v2 | ~1.56 ADA + g-token | **Updated with credential hash** |

## Minting Operations (Burn)

| Policy | Token | Quantity | Description |
|--------|-------|----------|-------------|
| course-state-policy | \<student_alias\> | **-1** | Course state token is **burned** |

## Global State Datum Update

The `local_state_map` value changes from course_state_token_hash to credential_hash:

**Before:**
```json
{
  "map": [
    { "k": { "bytes": "<courseId>" }, "v": { "bytes": "<course_state_token_hash>" } }
  ]
}
```

**After:**
```json
{
  "map": [
    { "k": { "bytes": "<courseId>" }, "v": { "bytes": "<credential_hash>" } }
  ]
}
```

The credential hash proves course completion and is permanently stored on-chain.

## Redeemers

Three redeemers are used:

**Course State (Spend)** - Constructor 3 = burn/claim:
```json
{ "constructor": 3, "fields": [] }
```

**Global State (Spend)** - Constructor 1 = update with credential:
```json
{
  "constructor": 1,
  "fields": [
    { "bytes": "<courseId>" },
    { "int": 0 },
    { "bytes": "" },
    { "bytes": "<course_state_policy>" },
    { "bytes": "<credential_hash>" }
  ]
}
```

**Mint (Burn)** - Constructor 4 = burn with proof:
```json
{
  "constructor": 4,
  "fields": [
    { "bytes": "<student_alias>" },
    { "list": [{ "bytes": "<completed_slt_hash>" }] }
  ]
}
```

## Reference Inputs

| ID | Description |
|----|-------------|
| script_ref | Script reference for validation |
| module_ref | Module reference for SLT verification |

## Notes

- Course state token is **burned** (negative mint quantity)
- Credential hash is stored permanently in global state
- Completed SLTs list in mint redeemer allows on-chain verification
- Student gets net ADA gain (~1.03 ADA) from released deposit
- No service fee for credential claims
- This completes the student's course journey
