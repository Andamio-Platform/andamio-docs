# Enroll in Course

Student enrolls in a course by minting a course state token, optionally with an initial assignment commitment.

## API Endpoint

```
POST /tx/v2/student/course/enroll
```

## Cost Breakdown

| Component | Amount |
|-----------|--------|
| Transaction Fee | ~0.40 ADA |
| Course State Deposit | ~1.45 ADA |
| Global State Delta | ~0.29 ADA |
| Service Fee | 0 ADA |
| **Total Wallet Delta** | **~2.14 ADA** |

The course state deposit (~1.45 ADA) is recoverable when claiming the credential.

## Request Body

```json
{
  "walletData": {
    "usedAddresses": ["addr_test1..."],
    "changeAddress": "addr_test1..."
  },
  "alias": "student_001",
  "courseId": "23a6bbce3a8deca8985764e847594f6956c9dc643e3f6c8efdba04e4",
  "commitData": {
    "sltHash": "8dcbe1b925d87e6c547bbd8071c23a712db4c32751454b0948f8c846e9246b5c",
    "assignmentInfo": "My first assignment submission"
  }
}
```

The `commitData` field is optional. If omitted, the student enrolls without an initial assignment.

## Transaction Pattern

**Mint and Create** - Mints course state token, creates course state UTxO, updates global state.

## Inputs

| ID | Type | Validator | Description |
|----|------|-----------|-------------|
| student_global_state | script | global-state-v2 | Student's global state (spent to update) |
| student_wallet | wallet | - | Student wallet for fees |

## Outputs

| ID | Type | Validator | Value | Description |
|----|------|-----------|-------|-------------|
| student_access_token_return | wallet | - | ~1.17 ADA + access token | Student retains access token |
| global_state_updated | script | global-state-v2 | ~1.56 ADA + g-token | Updated with course enrollment |
| course_state | script | course-state-validator | ~1.45 ADA + course state token | **New: student enrollment** |

## Minting Operations

| Policy | Token | Description |
|--------|-------|-------------|
| course-state-policy | \<student_alias\> | Course state token (name = student alias) |

## Global State Datum Update

The student's global state `local_state_map` is updated to include the course enrollment:

```json
{
  "constructor": 0,
  "fields": [
    { "bytes": "<student_alias>" },
    { "map": [
      { "k": { "bytes": "<courseId>" }, "v": { "bytes": "<course_state_token_hash>" } }
    ]}
  ]
}
```

## Course State Datum

With assignment commitment (constructor 1 = pending):

```json
{
  "constructor": 1,
  "fields": [
    { "bytes": "<slt_hash>" },
    { "bytes": "<assignment_info>" },
    { "list": [] }
  ]
}
```

## Reference Inputs

| ID | Description |
|----|-------------|
| script_ref | Script reference for validation |
| course_local_state_token | Course's LocalStateToken (embedded validator) |
| module_ref | Module reference for SLT validation |

## Notes

- Course state policy is **parameterized per course** (different from index-policy)
- Course state token name is the student's alias
- Global state is **spent** (not just referenced) to update the enrollment map
- No service fee for enrollment
- Deposit is recoverable on credential claim
