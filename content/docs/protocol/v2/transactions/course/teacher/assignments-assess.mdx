# Assess Assignments

Teacher accepts or rejects student assignment submissions.

## API Endpoint

```
POST /tx/v2/teacher/course/assignments/assess
```

## Cost Breakdown

| Component | Amount |
|-----------|--------|
| Transaction Fee | ~0.28 ADA |
| MinUTxO Refund | ~-0.07 ADA |
| Service Fee | 0 ADA |
| **Total Wallet Delta** | **~0.21 ADA** |

The wallet delta is lower than the tx fee because the datum shrinks when an assignment is accepted (pending → completed), releasing some locked ADA.

## Request Body

```json
{
  "walletData": {
    "usedAddresses": ["addr_test1..."],
    "changeAddress": "addr_test1..."
  },
  "alias": "james",
  "courseId": "23a6bbce3a8deca8985764e847594f6956c9dc643e3f6c8efdba04e4",
  "assignmentDecisions": [
    {
      "outcome": "accept",
      "alias": "student_001"
    }
  ]
}
```

## Transaction Pattern

**Spend and Recreate** - No minting. Consumes student's course state UTxO and recreates with updated datum.

## Inputs

| ID | Type | Validator | Description |
|----|------|-----------|-------------|
| teacher_access_token | wallet | - | Teacher's access token for auth |
| teacher_wallet | wallet | - | Teacher wallet for fees |
| student_course_state | script | course-state-validator | Student's pending assignment (spent) |

## Outputs

| ID | Type | Validator | Value | Description |
|----|------|-----------|-------|-------------|
| teacher_access_token_return | wallet | - | ~1.15 ADA + access token | Teacher retains access token |
| student_course_state_updated | script | course-state-validator | ~1.38 ADA + course state token | **Updated: completed assignment** |

## Datum Changes

The course state datum changes when an assignment is accepted:

**Before (pending):**
```json
{
  "constructor": 1,
  "fields": [
    { "bytes": "<slt_hash>" },
    { "bytes": "<assignment_info>" },
    { "list": [] }
  ]
}
```

**After (completed):**
```json
{
  "constructor": 0,
  "fields": [
    { "list": [{ "bytes": "<slt_hash>" }] }
  ]
}
```

## Redeemer

The course state validator uses constructor 2 for the assess action:

```json
{
  "constructor": 2,
  "fields": [
    { "bytes": "<teacher_alias>" }
  ]
}
```

## Reference Inputs

| ID | Description |
|----|-------------|
| module_ref | Module UTxO for SLT validation |
| course_nft_ref | Course LocalStateNFT for verification |

## Batching

Multiple assignment decisions can be batched in a single transaction:

```json
{
  "assignmentDecisions": [
    { "outcome": "accept", "alias": "student_001" },
    { "outcome": "accept", "alias": "student_002" },
    { "outcome": "refuse", "alias": "student_003" }
  ]
}
```

## Notes

- Teacher spends the **student's** course state UTxO (authorized by teacher alias in redeemer)
- Datum shrinks on accept (drops assignment_info), reducing minUTxO requirement
- No service fee for assessments
- Completed SLT hashes are accumulated in a list for credential claims
