Transactions for teachers managing courses.

## Transaction Overview

| Transaction | Description | Wallet Delta |
|------------|-------------|--------------|
| [Manage Modules](./modules-manage) | Mint, update, or burn modules | ~1.86 ADA (1 module) |
| [Assess Assignments](./assignments-assess) | Accept or reject student submissions | ~0.21 ADA |

## Notes

- Teachers must be listed in the course governance datum to perform these actions
- Module deposits are recoverable when modules are burned
- Assessment costs less than the tx fee due to datum compression
