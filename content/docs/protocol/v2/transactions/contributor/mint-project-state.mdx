# Mint Project State Transaction (V2)

## Overview

This transaction allows a contributor to mint a project state token, establishing their participation in a project. This is the first step for a contributor to begin working on a project.

## Protocol Description

The V2 implementation enhances the contributor onboarding process. The transaction mints a unique project state token that tracks the contributor's progress, commits, and rewards throughout their project participation.
