# Burn Project State Transaction (V2)

## Overview

This transaction allows contributors to burn their project state token when exiting a project. This cleanly removes their participation record and returns any locked resources.

## Protocol Description

The V2 burn mechanism ensures proper cleanup of contributor state. When burning their project state token, contributors must have claimed all pending rewards and completed all active commitments. The transaction releases any locked collateral and updates the project's contributor count.
