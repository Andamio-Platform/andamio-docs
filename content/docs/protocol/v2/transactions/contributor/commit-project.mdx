# Commit Project Transaction (V2)

## Overview

This transaction allows contributors to commit their completed work to a project. It updates the contributor's state and records their contribution in the project's history.

## Protocol Description

The V2 commit process includes enhanced validation and state tracking. When a contributor commits, the transaction verifies their project state token, validates the contribution, and updates both the contributor's state and the project's overall progress metrics.
