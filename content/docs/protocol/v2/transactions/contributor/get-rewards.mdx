# Get Rewards Transaction (V2)

## Overview

This transaction enables contributors to claim rewards they've earned through their project contributions. Rewards are distributed based on completed commits and project milestones.

## Protocol Description

The V2 rewards system implements improved distribution mechanics. Contributors can claim rewards after their contributions are validated, with automatic calculation based on their contribution weight and the project's reward pool allocation.
