## Transaction Patterns

| Pattern | Description | Transactions |
|---------|-------------|--------------|
| Mint and Create | Mints tokens, creates UTxOs | access-token, course-create, modules-manage, assignment-commit |
| Spend and Recreate | Updates existing UTxOs | teachers-update, assignments-assess, assignment-update |
| Burn and Update | Burns tokens, updates state | credential-claim |
