# Initialize Project - Step 1 Transaction (V2)

## Overview

This is the first step in initializing a new project on the platform. The instance admin creates the initial project state and sets up the foundation for project operations.

## Protocol Description

In V2, project initialization is split into two steps for better transaction size management and clearer separation of concerns. Step 1 establishes the core project state, mints necessary tokens, and prepares the project structure for the second initialization step.
