# Project Transactions

Transactions for creating and managing Andamio projects, including task management and contributor coordination.

## By Role

### Owner

Project owners can:
- [Manage Managers](/docs/protocol/v2/transactions/project/owner/managers/manage) - Add/remove project managers
- [Manage Blacklist](/docs/protocol/v2/transactions/project/owner/contributor-blacklist/manage) - Block/unblock contributors

### Manager

Project managers can:
- [Manage Tasks](/docs/protocol/v2/transactions/project/manager/tasks/manage) - Create, update, or burn tasks
- [Assess Tasks](/docs/protocol/v2/transactions/project/manager/tasks/assess) - Review contributor submissions

### Contributor

Project contributors can:
- [Task Commit](/docs/protocol/v2/transactions/project/contributor/task/commit) - Commit to a project task
- [Credential Claim](/docs/protocol/v2/transactions/project/contributor/credential/claim) - Claim project credential
