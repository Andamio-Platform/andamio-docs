Transactions available to project managers for coordinating work and contributors.

## Available Transactions

- [Tasks Manage](/docs/protocol/v2/transactions/project/manager/tasks/manage) - Create, update, or burn project tasks

## Role Overview

Project managers are designated by the project owner and have authority to:

1. **Define Tasks** - Create tasks with rewards and prerequisite requirements
2. **Update Tasks** - Modify existing task definitions
3. **Burn Tasks** - Remove tasks that are no longer needed
4. **Assess Submissions** - Review and accept/reject contributor work
