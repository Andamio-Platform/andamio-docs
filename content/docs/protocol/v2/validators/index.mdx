The Andamio Protocol V2 introduces enhanced validator architecture with improved state management, local state registration, and streamlined validation processes.

## Validator Systems

Core protocol state management:
- [Global State](/docs/protocol/v2/validators/global-state/global-state) - V1 compatibility validator
- [Global State V2](/docs/protocol/v2/validators/global-state/global-state-v2) - Enhanced V2 state management

### Global Registration Validators
New registration system for local state management:
- [Local State Registration](/docs/protocol/v2/validators/global/local-state-registration) - Registration validator for local states

## V2 Enhancements

- **Local State Registration**: New system for connecting local states to global V2
- **Enhanced State Management**: Improved course and contributor state tracking
- **CBOR Observers**: Comprehensive observer pattern for transaction validation
- **Migration Support**: Smooth transition from V1 to V2 validators
