# Protocol V2 Tokens

The Andamio Protocol V2 introduces enhanced token management with improved state tracking, local state registration, and streamlined access control.

## Token Systems

### Global State Tokens
Enhanced access tokens for protocol-wide permissions:
- [Access Token User](/docs/protocol/v2/tokens/global-state/access-token-user) - Higher-level user access token
- [Access Token Global State](/docs/protocol/v2/tokens/global-state/access-token-global-state) - Global state access token
- [Access Token Index](/docs/protocol/v2/tokens/global-state/access-token-index) - Index access token

### Global Registration Tokens
New registration system for local state management:
- [Local State Registration](/docs/protocol/v2/tokens/global/local-state-registration) - Registration token for local states

### Index Validator Tokens
Index system reference tokens:
- [Index Scripts Ref Token](/docs/protocol/v2/tokens/index-validators/index-scripts-ref-token) - Reference token for index scripts

### Local State Tokens
Local state management tokens:
- [Local State NFT](/docs/protocol/v2/tokens/local-state/local-state-nft) - NFT for local state representation

### Instance Tokens
Instance-level administrative and functional tokens:
- [Instance Admin Token](/docs/protocol/v2/tokens/instance/instance-admin-token) - Administrative privileges

### Course Tokens
Course-specific tokens for educational content:
- [Course State V2 Token](/docs/protocol/v2/tokens/course/course-state-v2-token) - Course state tracking

### Project Tokens
Project-specific tokens for contribution tracking:
- [Contributor State V2 Token](/docs/protocol/v2/tokens/project/contributor-state-v2-token) - Contributor tracking

## V2 Enhancements

- **Local State Registration**: New system for connecting local states to global V2
- **Enhanced State Tracking**: Improved contributor and course state management
- **Streamlined Access Control**: Simplified token-based permissions
