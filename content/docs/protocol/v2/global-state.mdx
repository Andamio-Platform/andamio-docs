# Global State

<Callout type="info">
This page is under active development. Detailed documentation is coming soon.
</Callout>

## Overview

Global State is the shared state layer that governs all Andamio instances. It manages:

- **Access Token Registration** — Tracking all minted access tokens across the protocol
- **Instance Registry** — The index of all course and project instances
- **Token Information** — Policy IDs and token metadata shared across the protocol

For technical details on the validators that enforce global state, see [Global State Validators](/docs/protocol/v2/validators/global-state).
