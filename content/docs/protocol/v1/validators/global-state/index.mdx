## Global State Validator

The Andamio Protocol is built on an Andamio Access token that becomes the holder's credential to access contribution and governance opportunities. Every Access Token corresponds to exactly one unique Global State.

### Global State Validator

The Global State system governs the credentials and ownership permissions associated with local instance on Andamio. It serves as a common source of truth for each Access Token, allowing targeted access control to applications and contribution opportunities.
