# Global Reference

The Global Reference validator stores reference scripts for Global_State and maintains data in its datum. This validator is part of the global blueprint and serves as a reference point for global state operations.

## Validator Diagram

![Global Reference](/diagrams/validators/global-ref.png)

## Blueprint Source

This validator is defined in the **global.plutus** blueprint.

## Redeemers

- `bytes` - Reference script storage validation

## Purpose

This validator serves as a reference script storage mechanism for global state validators, providing a secure and reliable way to store and access global state reference scripts and associated data.
