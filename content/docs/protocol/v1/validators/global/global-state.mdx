# Global State

The Global State validator manages global states and handles system-wide operations across the Andamio protocol. This validator is part of the global blueprint and serves as the central authority for global state management.

## Validator Diagram

![Global State](/diagrams/validators/global-state.png)

## Blueprint Source

This validator is defined in the **global.plutus** blueprint.

## Redeemers

### GlobalStateAction
- `AddTokenInformation` - Add new token information to global state
- `UpdateTokenInformation` - Update existing token information
- `AddAllowedCsTn` - Add allowed currency symbol and token name pairs
- `UpdateGlobalInfo` - Update global system information
- `ChangeIndexData` - Modify index data structures

## Purpose

This validator manages the global state of the Andamio protocol, handling token information, allowed currency symbols, and system-wide configuration changes. It serves as the central registry for protocol-wide settings and permissions.
