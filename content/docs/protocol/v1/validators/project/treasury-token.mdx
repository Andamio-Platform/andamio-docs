# Treasury Token

The Treasury Token validator manages treasury token minting and burning operations for project treasuries. This validator is part of the project blueprint and controls treasury token lifecycle.

<ValidatorDiagram
  system="project"
  validator="treasury-token"
/>

## Blueprint Source

This validator is defined in the **project.plutus** blueprint.

## Redeemers

### TreasuryTokenAction
- `MintTreasuryToken` - Create new treasury tokens
- `BurnTreasuryToken` - Remove treasury tokens from circulation

## Purpose

This validator manages the lifecycle of treasury tokens within projects, handling the minting and burning of tokens that represent treasury ownership and control. It ensures proper treasury token management and authorization.
