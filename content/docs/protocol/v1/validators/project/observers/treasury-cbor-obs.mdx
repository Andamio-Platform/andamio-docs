# Treasury CBOR Observer

The Treasury CBOR Observer validator observes the initialization of the Treasury_Scripts. This validator is part of the project blueprint and handles the CBOR observation for treasury operations.

## Blueprint Source

This validator is defined in the **project.plutus** blueprint.

## Redeemers

- `bytes` - Observer for Treasury_Scripts initialization

## Purpose

This validator serves as an observer for the initialization process of treasury validators, ensuring proper setup and validation of treasury management smart contracts for project funding.
