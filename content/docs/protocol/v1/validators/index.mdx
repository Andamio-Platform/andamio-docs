---
title: Andamio V1 Validators
description: Five validation systems built to initialize the Andamio Protocol
---

Andamio protocol consists of 5 systems that interact to provide essential functionality.

1. **Global system:** for tracking user credentials
2. **Index system:** ensures the uniqueness of access tokens
3. **Instance system:** enables the creation of local instances, where Course and Project are the first two examples of such local systems
4. **Course system:** tracks assignment completion and issues learning credentials
5. **Project system:** hosts project governance and treasury management, tracks task completion and issues project credentials
