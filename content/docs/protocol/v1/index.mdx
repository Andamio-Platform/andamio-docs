# Andamio Protocol V1

Andamio Protocol V1 is currently live on Cardano Mainnet. Anyone can interact with it via the initial Andamio Platform at [app.andamio.io](https://app.andamio.io).

The first version of Andamio introduces an initial Global State for tracking Course and Project credentials. It will be replaced by a more general system in Andamio Protocol V2. Following the release of Protocol V2, public APIs and an open-source Andamio SDK will go live. This documentation will be updated every step of the way.

The following documentation provides a reference for how the current protocol works, and it is divided into three sections:

1. [Validators](/docs/protocol/v1/validators)
2. [Transactions](/docs/protocol/v1/transactions)
3. [Global State](/docs/protocol/v1/global-state)
