# Remove Project Creators Transaction

![Remove Project Creators Transaction](/diagrams/transactions/admin-rm-project-creators.png)

## Overview

This transaction allows an instance admin to remove project creators from the platform. It requires multi-signature approval from both the instance admin and global admin.

## Transaction Metadata

- **Role**: InstanceAdmin
- **Category**: access_management
- **Required Tokens**: instanceAdminNFT
- **Estimated Fee**: 3.0 ADA
- **Multi-signature**: Yes (instanceAdmin + globalAdmin)

## Protocol Description

The transaction updates the project creators UTxO by removing specified creators from the authorized list. The creator list is updated while maintaining the permissions structure for remaining active creators.
