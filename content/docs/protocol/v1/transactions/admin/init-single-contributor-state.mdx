# Initialize Single Contributor State Transaction

## Overview

This transaction allows an instance admin to initialize a single contributor state instance. It creates a new contributor state with specific policy, prerequisite, and multisig configuration parameters.

## Protocol Description

The transaction references the contributor state provider scripts from the instance and mints a new contributor state instance token. The newly created contributor state includes:

- **Policy**: Defines the governance policy for the contributor state
- **Prerequisite**: Specifies requirements that must be met to participate
- **Multisig Configuration**: Native script CBOR and initiator address for multisig operations

This enables flexible initialization of contributor states with custom parameters for different project types and governance models.

## Transaction Flow

1. Instance admin provides their admin token as input
2. Transaction references the contributor state observer scripts from instance provider
3. New contributor state scripts are minted and sent to the instance scripts address
4. Contributor state observer validates the initialization via withdrawal
5. Admin token returns to admin wallet

## Use Cases

- Creating a new project with specific prerequisite requirements
- Initializing contributor states with custom governance policies
- Setting up multisig coordination for project management
