# Initialize Project Step 1 Transaction


## Overview

This transaction is the first step in initializing a new project. The instance admin begins the project setup process, transitioning the project state from pending to step 1 complete.

## Protocol Description

The transaction consumes a project state UTxO in pending status and outputs it with step1_complete status. This is part of a two-step initialization process where the project configuration is established incrementally.
