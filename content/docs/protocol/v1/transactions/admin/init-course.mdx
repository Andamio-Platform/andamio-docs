# Initialize Course Transaction


## Overview

This transaction allows an instance admin to initialize a new course in the platform. The course state transitions from pending to active status.

## Transaction Metadata

- **Role**: InstanceAdmin
- **Category**: course_management
- **Required Tokens**: instanceAdminNFT
- **Estimated Fee**: 4.0 ADA
- **Multi-signature**: Yes (instanceAdmin + globalAdmin)

## Protocol Description

The transaction consumes a course state UTxO in pending status and outputs it with active status. The course configuration is set during this initialization process, establishing the course parameters and making it available for use.
