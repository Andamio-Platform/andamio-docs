# General Transactions

Universal transactions that can be performed by any user to participate in the Andamio protocol.

## Available Transactions

### Access Token Mint
**Description**: User mints access tokens (100at, 222at) for protocol participation  
**Required Tokens**: userStateToken  
**Estimated Fee**: 2.5 ADA  
**Multi-signature**: No

Users must mint access tokens before participating in any protocol activities as students, contributors, or creators. These tokens serve as the entry mechanism for the platform and enable various role-based interactions.

---

Access tokens are the foundation of protocol participation and must be obtained before users can engage in course enrollment, project contribution, or content creation activities.
