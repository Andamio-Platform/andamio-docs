# Access Token Mint Transaction


## Overview

This transaction allows users to mint access tokens (100at, 222at) that are required for participating in various protocol activities as students, contributors, or creators.

## Protocol Description

The transaction creates access tokens that serve as the entry mechanism for protocol participation. Users provide their alias and information to mint tokens that enable them to join courses, contribute to projects, or create content within the Andamio platform. The user state is updated to track their access token holdings.
