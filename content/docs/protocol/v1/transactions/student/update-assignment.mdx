# Update Assignment Transaction

![Update Assignment Transaction](/diagrams/transactions/student-update-assignment.png)

## Overview

This transaction allows a student to update their assignment submission or progress information while working on a course assignment.

## Transaction Metadata

- **Role**: Student
- **Category**: assignment_management
- **Required Tokens**: localStateToken, 222at
- **Estimated Fee**: 1.5 ADA
- **Multi-signature**: No

## Protocol Description

The transaction updates the assignment state with new submission content or progress notes. The assignment status transitions to "updated" with a new timestamp, allowing students to iteratively improve their work before final submission.
