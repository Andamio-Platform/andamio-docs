# Mint Local State Transaction

![Mint Local State Transaction](/diagrams/transactions/student-mint-local-state.png)

## Overview

This transaction allows a student to mint a local state token that tracks their participation and progress within a specific course.

## Transaction Metadata

- **Role**: Student
- **Category**: state_management
- **Required Tokens**: 100at, 222at
- **Estimated Fee**: 2.0 ADA
- **Multi-signature**: No

## Protocol Description

The transaction creates a local state token that serves as the student's course enrollment record. This token maintains assignment progress, grades, and other course-specific data throughout the student's participation in the course.
