# Burn Local State Transaction

![Burn Local State Transaction](/diagrams/transactions/student-burn-local-state.png)

## Overview

This transaction allows a student to burn their local state token and transition their course data to the global state, typically upon course completion.

## Transaction Metadata

- **Role**: Student
- **Category**: state_management
- **Required Tokens**: localStateToken, 222at
- **Estimated Fee**: 2.0 ADA
- **Multi-signature**: No

## Protocol Description

The transaction burns the student's local state token and moves their completed assignment data and grades to the global state. This represents the completion of the course and the permanent recording of the student's achievements in the global ledger.
