# Course Creator Transactions

Course creators manage educational content and evaluate student assignments through these transactions that control course modules and grading workflows.

## Available Transactions

### Content Management

#### Mint Module Tokens
**Description**: Course creator mints module tokens for course content  
**Required Tokens**: 100at, courseCreatorNFT  
**Estimated Fee**: 0 ADA  
**Multi-signature**: No

### Assignment Evaluation

#### Accept Assignment
**Description**: Course creator accepts and approves a student's assignment submission  
**Required Tokens**: courseCreatorNFT, 100at  
**Estimated Fee**: 0 ADA  
**Multi-signature**: No

#### Deny Assignment
**Description**: Course creator denies a student's assignment submission  
**Required Tokens**: courseCreatorNFT, 100at  
**Estimated Fee**: 0 ADA  
**Multi-signature**: No

---

Course creators first establish course content through module token minting, then evaluate student work through the assignment acceptance/denial workflow. Accepted assignments result in module completion tokens being issued to students, while denied assignments can include feedback and resubmission permissions.
