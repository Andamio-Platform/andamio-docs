# ContributorUnlockProject

Contributor unlocks and leaves a project

## Overview

This transaction is performed by **Contributor** users and falls under the **Project Management** category.

## Prerequisites

### Required Tokens
The following tokens are required to execute this transaction:

- **100at**
- **contributorNFT**
- **projectStateToken**

## Transaction Details

### Estimated Fee
**2.0 ADA**

- **Role:** Contributor
