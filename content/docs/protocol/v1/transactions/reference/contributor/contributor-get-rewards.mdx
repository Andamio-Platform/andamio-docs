# ContributorGetRewards

Contributor claims rewards for completed project work

## Overview

This transaction is performed by **Contributor** users and falls under the **Reward Management** category.

## Prerequisites

### Required Tokens
The following tokens are required to execute this transaction:

- **100at**
- **contributorNFT**
- **projectCompletionToken**

## Transaction Details

### Estimated Fee
**2.5 ADA**

### Transaction Type
- **Role:** Contributor
- **Category:** Reward Management
- **Multi-Signature:** No
