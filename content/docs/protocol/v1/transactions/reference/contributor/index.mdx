# Contributor Transactions

This section contains all transactions available to **Contributor** users in the Andamio protocol.

## Available Transactions

### [ContributorAddInfo](./contributor-add-info.mdx)

Contributor adds or updates their profile information

- **Category:** Profile Management
- **Fee:** 1.5 ADA
- **Multi-Sig:** No

### [ContributorBurnContributorInfo](./contributor-burn-contributor-info.mdx)

Contributor burns their contributor info token

- **Category:** Profile Management
- **Fee:** 1.5 ADA
- **Multi-Sig:** No

### [ContributorMintProjectState](./contributor-mint-project-state.mdx)

Contributor mints project state token to track participation

- **Category:** State Management
- **Fee:** 2.5 ADA
- **Multi-Sig:** No

### [ContributorGetRewards](./contributor-get-rewards.mdx)

Contributor claims rewards for completed project work

- **Category:** Reward Management
- **Fee:** 2.5 ADA
- **Multi-Sig:** No

### [ContributorCommitProject](./contributor-commit-project.mdx)

Contributor commits to working on a specific project

- **Category:** Project Management
- **Fee:** 3.0 ADA
- **Multi-Sig:** No

### [ContributorUnlockProject](./contributor-unlock-project.mdx)

Contributor unlocks and leaves a project

- **Category:** Project Management
- **Fee:** 2.0 ADA
- **Multi-Sig:** No
