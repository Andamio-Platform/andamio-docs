# StudentLeaveAssignment

Student leaves an assignment they previously committed to

## Overview

This transaction is performed by **Student** users and falls under the **Assignment Management** category.

## Prerequisites

### Required Tokens
The following tokens are required to execute this transaction:

- **localStateToken**
- **222at**

## Transaction Details

### Estimated Fee
**1.5 ADA**

### Transaction Type
- **Role:** Student
- **Category:** Assignment Management
- **Multi-Signature:** No

## Transaction Structure

This transaction includes:

### Inputs
The transaction consumes the following UTxOs:
- User wallet UTxO
- Protocol state UTxOs
- Authorization tokens

### Reference Inputs
The transaction references:
- Parameter reference scripts
- Instance reference data
- Global state information

### Outputs
The transaction produces:
- Updated state UTxOs
- Modified user wallet
- Any newly minted tokens
