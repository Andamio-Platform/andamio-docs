# Student Transactions

This section contains all transactions available to **Student** users in the Andamio protocol.

## Available Transactions

### [StudentMintLocalState](./student-mint-local-state.mdx)

Student mints local state token for course participation

- **Category:** State Management
- **Fee:** 2.0 ADA
- **Multi-Sig:** No

### [StudentBurnLocalState](./student-burn-local-state.mdx)

Student burns local state token and moves to global state

- **Category:** State Management
- **Fee:** 2.0 ADA
- **Multi-Sig:** No

### [StudentUpdateAssignment](./student-update-assignment.mdx)

Student updates their assignment submission or information

- **Category:** Assignment Management
- **Fee:** 1.5 ADA
- **Multi-Sig:** No

### [MintLocalState](./mint-local-state.mdx)

Student mints local state token to participate in course

- **Category:** State Management
- **Fee:** 2.0 ADA
- **Multi-Sig:** No

### [StudentLeaveAssignment](./student-leave-assignment.mdx)

Student leaves an assignment they previously committed to

- **Category:** Assignment Management
- **Fee:** 1.5 ADA
- **Multi-Sig:** No

### [StudentCommitToAssignment](./student-commit-to-assignment.mdx)

Student commits to working on a specific module assignment

- **Category:** Assignment Management
- **Fee:** 2.5 ADA
- **Multi-Sig:** No
