# MintLocalState

Student mints local state token to participate in course

## Overview

This transaction is performed by **Student** users and falls under the **State Management** category.

## Prerequisites

### Required Tokens
The following tokens are required to execute this transaction:

- **100at**
- **222at**

## Transaction Details

### Estimated Fee
**2.0 ADA**

### Transaction Type
- **Role:** Student
- **Category:** State Management
- **Multi-Signature:** No

## Transaction Structure

This transaction includes:

### Inputs
The transaction consumes the following UTxOs:
- User wallet UTxO
- Protocol state UTxOs
- Authorization tokens

### Reference Inputs
The transaction references:
- Parameter reference scripts
- Instance reference data
- Global state information

### Outputs
The transaction produces:
- Updated state UTxOs
- Modified user wallet
- Any newly minted tokens
