# CourseCreatorDenyAssignment

Course creator denies a student's assignment submission

## Overview

This transaction is performed by **CourseCreator** users and falls under the **Assignment Management** category.

## Prerequisites

### Required Tokens
The following tokens are required to execute this transaction:

- **courseCreatorNFT**
- **100at**

## Transaction Details

### Estimated Fee
**2.0 ADA**

### Transaction Type
- **Role:** CourseCreator
- **Category:** Assignment Management
- **Multi-Signature:** No

This transaction includes:

### Inputs
The transaction consumes the following UTxOs:

### Reference Inputs
The transaction references:

### Outputs
The transaction produces:
