# CourseCreatorMintModuleTokens

Course creator mints module tokens for course content

## Overview

This transaction is performed by **CourseCreator** users and falls under the **Course Management** category.

## Prerequisites

### Required Tokens
The following tokens are required to execute this transaction:

- **100at**
- **courseCreatorNFT**

## Transaction Details

### Estimated Fee
**3.5 ADA**

### Transaction Type
- **Role:** CourseCreator
- **Category:** Course Management
- **Multi-Signature:** No

## Transaction Structure

This transaction includes:

### Inputs
The transaction consumes the following UTxOs:
- User wallet UTxO
- Protocol state UTxOs
- Authorization tokens

### Reference Inputs
The transaction references:
- Parameter reference scripts
- Instance reference data
- Global state information

### Outputs
The transaction produces:
- Updated state UTxOs
- Modified user wallet
- Any newly minted tokens
