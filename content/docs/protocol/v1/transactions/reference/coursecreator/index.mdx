# CourseCreator Transactions

This section contains all transactions available to **CourseCreator** users in the Andamio protocol.

## Available Transactions

### [CourseCreatorMintModuleTokens](./course-crestor-mint-module-tokens.mdx)

Course creator mints module tokens for course content

- **Category:** Course Management
- **Fee:** 3.5 ADA
- **Multi-Sig:** No

### [CourseCreatorDenyAssignment](./course-creator-deny-assignment.mdx)

Course creator denies a student's assignment submission

- **Category:** Assignment Management
- **Fee:** 2.0 ADA
- **Multi-Sig:** No

### [CourseCreatorAcceptAssignment](./course-creator-accept.assignment.mdx)

Course creator accepts and approves a student's assignment submission

- **Category:** Assignment Management
- **Fee:** 2.5 ADA
- **Multi-Sig:** No
