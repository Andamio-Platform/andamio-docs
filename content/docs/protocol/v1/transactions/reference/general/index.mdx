# General Transactions

This section contains all transactions available to **General** users in the Andamio protocol.

## Available Transactions

### [AccessTokenMint](./access-token-mint.mdx)

User mints access tokens (100at, 222at) for protocol participation

- **Category:** Access Management
- **Fee:** 2.5 ADA
- **Multi-Sig:** No
