# AccessTokenMint

User mints access tokens (100at, 222at) for protocol participation

## Overview

This transaction is performed by **General** users and falls under the **Access Management** category.

## Prerequisites

### Required Tokens
The following tokens are required to execute this transaction:

- **userStateToken**

## Transaction Details

### Estimated Fee
**2.5 ADA**

### Transaction Type
- **Role:** General
- **Category:** Access Management
- **Multi-Signature:** No

## Transaction Structure

This transaction includes:

### Inputs
The transaction consumes the following UTxOs:
- User wallet UTxO
- Protocol state UTxOs
- Authorization tokens

### Reference Inputs
The transaction references:
- Parameter reference scripts
- Instance reference data
- Global state information

### Outputs
The transaction produces:
- Updated state UTxOs
- Modified user wallet
- Any newly minted tokens
