# ProjectCreator Transactions

This section contains all transactions available to **ProjectCreator** users in the Andamio protocol.

## Available Transactions

### [ProjectCreatorManageTreasury](./project-creator-manage-treasury-token.mdx)

Project creator manages treasury funds and distribution

- **Category:** Treasury Management
- **Fee:** 4.5 ADA
- **Multi-Sig:** Yes

### [TreasuryAddFunds](./treasury-add-funds.mdx)

Project creator adds additional funds to project treasury

- **Category:** Treasury Management
- **Fee:** 2.0 ADA
- **Multi-Sig:** No

### [ProjectCreatorRefuseProject](./project-creator-refuse-project.mdx)

Project creator refuses a project proposal with detailed reason

- **Category:** Project Management
- **Fee:** 1.5 ADA
- **Multi-Sig:** No

### [ProjectCreatorDenyProject](./project-creator-deny-project.mdx)

Project creator denies a contributor's project proposal

- **Category:** Project Management
- **Fee:** 2.0 ADA
- **Multi-Sig:** No

### [ProjectCreatorAcceptProject](./project-creator-accept-project.mdx)

Project creator accepts a contributor's project proposal or application

- **Category:** Project Management
- **Fee:** 3.0 ADA
- **Multi-Sig:** No

### [ProjectCreatorMintTreasuryToken](./project-creator-mint-treasury-token.mdx)

Project creator mints treasury token to initialize project treasury

- **Category:** Treasury Management
- **Fee:** 3.5 ADA
- **Multi-Sig:** No
