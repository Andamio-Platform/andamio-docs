# InstanceAdmin Transactions

This section contains all transactions available to **InstanceAdmin** users in the Andamio protocol.

## Available Transactions

### [AdminInitCourse](./admin-init-course.mdx)

Instance admin initializes a new course in the platform

- **Category:** Course Management
- **Fee:** 4.0 ADA
- **Multi-Sig:** Yes

### [AdminInitProjectStep1](./admin-init-project-step-1.mdx)

Instance admin initializes a new project (step 1 of 2)

- **Category:** Instance Management
- **Fee:** 3.5 ADA
- **Multi-Sig:** Yes

### [AdminRmCourseCreators](./admin-rm-course-creators.mdx)

Instance admin removes course creators from the platform

- **Category:** Access Management
- **Fee:** 3.0 ADA
- **Multi-Sig:** Yes

### [AdminAddCourseCreators](./admin-add-course-creators.mdx)

Instance admin adds new course creators to the platform

- **Category:** Access Management
- **Fee:** 3.0 ADA
- **Multi-Sig:** Yes

### [AdminRmProjectCreators](./admin-rm-project-creators.mdx)

Instance admin removes project creators from the platform

- **Category:** Access Management
- **Fee:** 3.0 ADA
- **Multi-Sig:** Yes

### [AdminInitProjectStep2](./admin-init-project-step-2.mdx)

Instance admin completes project initialization (step 2 of 2)

- **Category:** Instance Management
- **Fee:** 4.0 ADA
- **Multi-Sig:** Yes

### [AdminAddProjectCreators](./admin-add-project-creators.mdx)

Instance admin adds new project creators to the platform

- **Category:** Access Management
- **Fee:** 3.0 ADA
- **Multi-Sig:** Yes
