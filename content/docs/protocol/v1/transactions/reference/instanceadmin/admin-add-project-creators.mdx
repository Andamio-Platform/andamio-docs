# AdminAddProjectCreators

Instance admin adds new project creators to the platform

## Overview

This transaction is performed by **InstanceAdmin** users and falls under the **Access Management** category.

## Prerequisites

### Required Tokens
The following tokens are required to execute this transaction:

- **instanceAdminNFT**

### Multi-Signature Requirements
This transaction requires multiple signatures:

**Required Signatures:** instanceAdmin + globalAdmin

## Transaction Details

### Estimated Fee
**3.0 ADA**

### Transaction Type
- **Role:** InstanceAdmin
- **Category:** Access Management
- **Multi-Signature:** Yes
