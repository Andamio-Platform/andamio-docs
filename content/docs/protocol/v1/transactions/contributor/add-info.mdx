# Add Info Transaction

![Add Info Transaction](/diagrams/transactions/contributor-add-info.png)

## Overview

This transaction allows a contributor to add or update their profile information in the platform. It establishes the contributor's identity and metadata within the system.

## Transaction Metadata

- **Role**: Contributor
- **Category**: profile_management
- **Required Tokens**: 100at, contributorNFT
- **Estimated Fee**: 1.5 ADA
- **Multi-signature**: No

## Protocol Description

The transaction allows contributors to create or update their profile data, including alias information, skills, and other relevant metadata that will be used throughout their participation in the platform.
