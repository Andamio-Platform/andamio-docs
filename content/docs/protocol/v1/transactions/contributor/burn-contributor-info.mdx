# Burn Contributor Info Transaction

![Burn Contributor Info Transaction](/diagrams/transactions/contributor-burn-contributor-info.png)

## Overview

This transaction allows a contributor to burn their contributor info token, effectively removing their profile information from the platform.

## Transaction Metadata

- **Role**: Contributor
- **Category**: profile_management
- **Required Tokens**: contributorInfoToken, contributorNFT
- **Estimated Fee**: 1.5 ADA
- **Multi-signature**: No

## Protocol Description

The transaction consumes the contributor's info token, permanently removing their profile data and associated metadata from the platform. This is typically used when a contributor wants to exit the system completely.
