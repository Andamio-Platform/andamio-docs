# Mint Project State Transaction


## Overview

This transaction allows a contributor to mint a project state token that tracks their participation in a specific project.

## Transaction Metadata

- **Role**: Contributor
- **Category**: state_management
- **Required Tokens**: 100at, contributorNFT
- **Estimated Fee**: 2.5 ADA
- **Multi-signature**: No

## Protocol Description

This is a state management transaction where a contributor mints project state tokens to track their participation in a specific project. It involves:

- **Global state updates** - Tracking user participation in the project
- **Minting new contributor state tokens** - Creating proof of project commitment  
- **Reference inputs for validation** - Ensuring proper authorization via instance scripts
- **Complex datum structures** - Managing project lists and participation flags

The transaction creates a new project state token that represents the contributor's participation and progress within a specific project. This token serves as a reference for tracking work completion and reward eligibility.
