# Contributor Transactions

Contributors are Access Token Holders participating in Project Local States. Contributors earn Credentials by completing Courses (where they're called "students"), which serve as prerequisites for accessing Project participation. Contributors participate in projects through these transactions that manage their profile, project commitments, and reward claims.

## Available Transactions

### Profile Management

#### Add Info
**Description**: Contributor adds or updates their profile information  
**Required Tokens**: 100at, contributorNFT  
**Estimated Fee**: 1.5 ADA  
**Multi-signature**: No

#### Burn Contributor Info
**Description**: Contributor burns their contributor info token  
**Required Tokens**: contributorInfoToken, contributorNFT  
**Estimated Fee**: 1.5 ADA  
**Multi-signature**: No

### Project Participation

#### Mint Project State
**Description**: Contributor mints project state token to track participation  
**Required Tokens**: 100at, contributorNFT  
**Estimated Fee**: 2.5 ADA  
**Multi-signature**: No

#### Commit Project
**Description**: Contributor commits to working on a specific project  
**Required Tokens**: 100at, contributorNFT  
**Estimated Fee**: 3.0 ADA  
**Multi-signature**: No

#### Unlock Project
**Description**: Contributor unlocks and leaves a project  
**Required Tokens**: 100at, contributorNFT, projectStateToken  
**Estimated Fee**: 2.0 ADA  
**Multi-signature**: No

### Reward Management

#### Get Rewards
**Description**: Contributor claims rewards for completed project work  
**Required Tokens**: 100at, contributorNFT, projectCompletionToken  
**Estimated Fee**: 2.5 ADA  
**Multi-signature**: No

---

The contributor workflow typically follows: profile creation → project state minting → project commitment → work completion → reward claiming. Contributors can manage multiple projects simultaneously and leave projects when needed.
