# Unlock Project Transaction

![Unlock Project Transaction](/diagrams/transactions/contributor-unlock-project.png)

## Overview

This transaction allows a contributor to unlock and leave a project, retrieving their staked tokens and removing themselves from the project's contributor list.

## Transaction Metadata

- **Role**: Contributor
- **Category**: project_management
- **Required Tokens**: 100at, contributorNFT, projectStateToken
- **Estimated Fee**: 2.0 ADA
- **Multi-signature**: No

## Protocol Description

The transaction removes the contributor from the project's contributor list and burns or returns the project state token. This allows the contributor to exit the project and potentially reclaim any staked tokens, depending on the project's completion status and terms.
