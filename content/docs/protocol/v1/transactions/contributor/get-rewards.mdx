# Get Rewards Transaction


## Overview

This transaction allows a contributor to claim rewards for completed project work. The contributor must provide proof of completion to withdraw rewards from the project treasury.

## Protocol Description

The transaction distributes rewards from the project treasury to the contributor based on completion proof. The treasury UTxO is updated with reduced funds and reward tokens, while the contributor receives their earned rewards. The completion proof validates the contributor's work according to project criteria.
