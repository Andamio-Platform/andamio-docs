# V1 Transactions - Deprecated

<Callout type="warn">
**V1 transactions are deprecated.** The Andamio protocol has migrated to V2, which provides a simplified transaction model with improved security and lower costs.
</Callout>

## Migration to V2

All V1 transaction functionality has been replaced by V2 endpoints:

| V1 Transaction | V2 Replacement |
|----------------|----------------|
| Access Token Mint | [Global Access Token Mint](/docs/protocol/v2/transactions/global/general/access-token/mint) |
| Init Course | [Course Create](/docs/protocol/v2/transactions/instance/owner/course/create) |
| Init Project | [Project Create](/docs/protocol/v2/transactions/instance/owner/project/create) |
| Add/Remove Course Creators | [Teachers Manage](/docs/protocol/v2/transactions/course/owner/teachers/manage) |
| Mint Module Tokens | [Modules Manage](/docs/protocol/v2/transactions/course/teacher/modules/manage) |
| Mint Local State | [Assignment Commit](/docs/protocol/v2/transactions/course/student/assignment/commit) |
| Commit to Assignment | [Assignment Commit](/docs/protocol/v2/transactions/course/student/assignment/commit) |
| Update Assignment | [Assignment Update](/docs/protocol/v2/transactions/course/student/assignment/update) |
| Accept/Deny Assignment | [Assignments Assess](/docs/protocol/v2/transactions/course/teacher/assignments/assess) |
| Burn Local State | [Credential Claim](/docs/protocol/v2/transactions/course/student/credential/claim) |

## Key V2 Improvements

- **Unified enrollment + commitment**: Students now enroll and commit to assignments in a single transaction
- **Simplified role structure**: Owner, Teacher/Manager, Student/Contributor
- **Lower fees**: Optimized transaction sizes reduce costs
- **Better batching**: Teachers can assess multiple assignments in one transaction
- **Credential system**: Credential hashes stored permanently in global state
