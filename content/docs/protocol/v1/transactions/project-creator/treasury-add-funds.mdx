# Treasury Add Funds Transaction

Anyone can add funds to a treasury any time.

## Overview

This transaction allows a project creator to add additional funds to an existing project treasury, increasing the available budget for contributor rewards.

## Protocol Description

The transaction increases the treasury balance by transferring additional ADA from the creator's wallet to the treasury UTxO. The funding history is updated to track the additional investment, maintaining a complete record of treasury funding sources.
