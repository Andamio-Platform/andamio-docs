# Accept Project Transaction


## Overview

This transaction allows a project creator to accept a contributor's project proposal or application. Upon acceptance, an active project token is minted and the project moves into active status.

## Protocol Description

The transaction consumes a project proposal UTxO and creates an active project UTxO with established payment terms and milestone schedules. An active project token is minted to represent the ongoing work relationship between creator and contributor.
