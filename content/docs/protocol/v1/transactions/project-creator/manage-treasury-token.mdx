# Manage Treasury Token Transaction


## Overview

This transaction allows a project creator to manage treasury funds and distribution, including reward payments to contributors. Requires multi-signature approval from both project creator and instance admin.

## Protocol Description

The transaction manages treasury operations including fund distribution, reward allocation updates, and payment scheduling. The treasury UTxO is updated with new balances while reward payments are distributed to eligible contributors. Admin approval ensures oversight of significant treasury operations.
