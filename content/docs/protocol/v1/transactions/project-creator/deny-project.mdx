# Deny Project Transaction

![Deny Project Transaction](/diagrams/transactions/project-creator-deny-project.png)

## Overview

This transaction allows a project creator to deny a contributor's project proposal, effectively rejecting the application to work on the project.

## Transaction Metadata

- **Role**: ProjectCreator
- **Category**: project_management
- **Required Tokens**: 100at, projectCreatorNFT
- **Estimated Fee**: 2.0 ADA
- **Multi-signature**: No

## Protocol Description

The transaction processes a project proposal rejection, updating the proposal status and providing feedback to the contributor. This allows the creator to decline projects that don't meet requirements or aren't suitable for their needs.
