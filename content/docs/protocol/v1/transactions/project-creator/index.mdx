# Project Creator Transactions

Project creators manage project lifecycles, treasury operations, and contributor relationships through these transactions that control project funding and participant approval.

## Available Transactions

### Treasury Management

#### Mint Treasury Token
**Description**: Project creator mints treasury token to initialize project treasury  
**Required Tokens**: 100at, projectCreatorNFT  
**Estimated Fee**: 0 ADA  
**Multi-signature**: No

#### Treasury Add Funds
**Description**: Project creator adds additional funds to project treasury  
**Required Tokens**: 100at, projectCreatorNFT, treasuryToken  
**Estimated Fee**: 0 ADA  
**Multi-signature**: No

#### Manage Treasury Token
**Description**: Project creator manages treasury funds and distribution  
**Required Tokens**: 100at, projectCreatorNFT, treasuryToken  
**Estimated Fee**: 0 ADA  
**Multi-signature**: Yes (projectCreator + instanceAdmin)

### Contributor Management

#### Accept Project
**Description**: Project creator accepts a contributor's project proposal or application  
**Required Tokens**: 100at, projectCreatorNFT  
**Estimated Fee**: 0 ADA  
**Multi-signature**: No

#### Deny Project
**Description**: Project creator denies a contributor's project proposal  
**Required Tokens**: 100at, projectCreatorNFT  
**Estimated Fee**: 0 ADA  
**Multi-signature**: No

#### Refuse Project
**Description**: Project creator refuses a project proposal with detailed reason  
**Required Tokens**: 100at, projectCreatorNFT  
**Estimated Fee**: 0 ADA  
**Multi-signature**: No

---

The project creator workflow typically involves: treasury initialization → funding → contributor evaluation and acceptance → ongoing treasury management. Treasury distribution operations require instance admin approval for additional oversight of significant fund movements.
