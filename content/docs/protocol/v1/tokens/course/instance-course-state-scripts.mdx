# Instance Course State Scripts

The Instance Course State Scripts token is an instance-specific reference token that provides access to course state scripts functionality within course instances.

## Token Details

- **Asset ID**: `<instance_policyid>.CourseStateScripts`
- **System**: Course
- **Storage Location**: Course validator
