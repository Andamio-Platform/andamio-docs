# Module Token

The Module Token is a credential token that represents completion of specific course modules and enables module-based validation within assignments.

## Token Details

- **Asset ID**: `<module_policyid>.<module_code>`
- **System**: Course
- **Storage Location**: Module validator

## Usage

### Minted In
- [course-creator-mint-module-tokens](/docs/protocol/v1/transactions/course-creator/mint-module-tokens)

### Used In
This token is not used in any documented transactions.

### Referenced In
- student-commit-to-assignment

### Burned In
This token is not burned in any documented transactions.
