# Instance Module Scripts

The Instance Module Scripts token is an instance-specific reference token that provides access to module scripts functionality within course instances.

## Token Details

- **Asset ID**: `<instance_policyid>.ModuleScripts`
- **System**: Course
- **Storage Location**: Course validator

## Usage

### Minted In
- admin-init-course

### Used In
This token is not used in any documented transactions.

### Referenced In
This token is not used as a reference input in any documented transactions.

### Burned In
This token is not burned in any documented transactions.
