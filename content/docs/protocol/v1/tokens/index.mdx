## Overview

This page provides a comprehensive overview of all tokens in the Andamio Protocol v1, organized by system and usage patterns. All tokens follow the dot notation reference system defined in the [validator registry](/docs/protocol/v1/address-policy-variables).

Token references use the format `system.token-name` which maps to registry paths at `systems > system > tokens > token-name`. Each token has an `asset-id` field containing the actual blockchain identifier in the format `<policyid>.<tokenname>`.

## Token Systems

The protocol organizes tokens into five main systems:

### Global State System
- **access-token-user** - User-level access token
- **access-token-global-state** - Global state access token  
- **access-token-index** - Index access token

### Index Validators System
- **index-admin-token** - Index administration token
- **index-scripts-ref-token** - Index scripts reference token

### Instance System
- **instance-admin-token** - Instance administration token
- **course-nft** - Course NFT for course identification
- **course-state-scripts** - Course state script references
- **module-scripts** - Module script references
- **assignment-validator** - Assignment validator references
- **project-nft** - Project NFT for project identification
- **treasury-token** - Treasury token references
- **escrow1** - Escrow validator references
- **treasury-scripts** - Treasury script references
- **contributor-state-scripts** - Contributor state script references

### Course System
- **course-nft** - Course identification NFT
- **instance-assignment-validator** - Assignment validator instance
- **instance-module-scripts** - Module scripts instance
- **instance-course-state-scripts** - Course state scripts instance
- **course-state-token** - Student course participation token
- **module-token** - Course module completion credential

### Project System
- **project-nft** - Project identification NFT
- **project-instance-treasury-token** - Treasury token instance
- **project-instance-escrow1** - Escrow instance
- **project-instance-treasury-scripts** - Treasury scripts instance
- **project-instance-contributor-state-scripts** - Contributor state scripts instance
- **contributor-state-token** - Contributor participation token
- **treasury-token** - Treasury management token

## Token Usage Patterns

Each token in the registry tracks its lifecycle through four usage fields:

- **minted-in** - Transaction that creates the token
- **used-in** - Transactions that consume the token as input
- **referenced-in** - Transactions that reference the token without consuming
- **burned-in** - Transactions that destroy the token
