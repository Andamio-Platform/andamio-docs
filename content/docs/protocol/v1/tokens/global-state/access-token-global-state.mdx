# Access Token Global State

The Access Token Global State is a basic access token that is stored in the global state validator and enables core protocol state operations. This token provides permissions for global state management and user state transitions.

## Token Details

- **Asset ID**: `<access_token_policyid>.100<alias>`
- **System**: Global State
- **Storage Location**: Global state validator
