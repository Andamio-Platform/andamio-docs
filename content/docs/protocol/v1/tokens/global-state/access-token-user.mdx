# Access Token User

The Access Token User is a higher-level access token that is stored in user wallets and enables various protocol interactions. This token provides elevated permissions for contributors, course creators, project creators, and students within the Andamio protocol.

## Token Details

- **Asset ID**: `<access_token_policyid>.222<alias>`
- **System**: Global State
- **Storage Location**: User wallet
