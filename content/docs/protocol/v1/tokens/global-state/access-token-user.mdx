# Access Token User

The Access Token User is a higher-level access token that is stored in user wallets and enables various protocol interactions. This token provides elevated permissions for Access Token Holders who participate as contributors (in Project Local States), students (in Course Local States), course creators, and project creators within the Andamio protocol.
