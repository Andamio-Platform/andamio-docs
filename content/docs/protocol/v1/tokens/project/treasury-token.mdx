# Treasury Token

The Treasury Token is a project-specific token that represents treasury escrow management capabilities and enables treasury operations within project instances.

## Token Details

- **Asset ID**: `<treasury_token_policyid>.<escrow_hash>`
- **System**: Project
- **Storage Location**: Treasury validator
