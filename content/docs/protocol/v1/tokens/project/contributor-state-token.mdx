# Contributor State Token

The Contributor State Token is a contributor-specific token that tracks project participation and enables contributor interactions within project operations and state management.

## Token Details

- **Asset ID**: `<contributor_state_policyid>.<alias>`
- **System**: Project
- **Storage Location**: Contributor state validator
