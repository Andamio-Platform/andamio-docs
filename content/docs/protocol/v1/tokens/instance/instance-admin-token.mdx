# Instance Admin Token

The Instance Admin Token is an administrative token that provides elevated permissions for instance management operations, including course and project initialization and creator management.

## Token Details

- **Asset ID**: `<instance_admin_policyid>.InstanceAdmin`
- **System**: Instance
- **Storage Location**: Instance validator

## Usage

### Minted In
This token is not minted in any documented transactions.

- admin-add-course-creators
- admin-rm-course-creators
- admin-init-project-step-1
- admin-init-project-step-2
- admin-add-project-creators
- admin-rm-project-creators

### Referenced In
This token is not used as a reference input in any documented transactions.

### Burned In
This token is not burned in any documented transactions.
