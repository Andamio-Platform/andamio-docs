### Andamio Protocol

Andamio is a decentralized protocol for the creation and management of immutable, interopable credentials. It provides a minimal global standard for placing credentials the Cardano blockchain, and a flexible toolkit for defining and using new credentials.

This documentation is a work in progress, and we are grateful that you are reading it. We will continue to refine the docs throughout Q3 2025, and we are grateful for your feedback. Please reach out on [our Discord](https://discord.gg/abBbsGZpZ5), on [Twitter @AndamioPlatform](https://twitter.com/AndamioPlatform), or [via GitHub](https://github.com/Andamio-Platform/andamio-docs).

1. Reusable, maintainable, and up-to-date documentation for the Andamio Protocol.
