The Andamio API is the developer product: REST endpoints and guides for issuing,
verifying, and gating on-chain credentials from your own stack.

- **[Getting started](/docs/api/getting-started)** — set up and make your first call.
- **[Developer guides](/docs/api/guides)** — authentication, transactions, billing, and more.
- **[Reference](/docs/api/reference)** — environments and configuration.

For the full endpoint reference, see the live API docs at
[api.andamio.io](https://api.andamio.io).
