## Best Practices

Regardless of framework, follow these principles:

1. **Always register transactions** - Even if you don't poll for status, registering ensures the database gets updated automatically.

2. **Start polling after ~30 seconds** - Cardano block time is typically 20-40 seconds. Polling earlier wastes API calls.

3. **Poll every 10-15 seconds** - This balances responsiveness with API efficiency.

4. **Handle all terminal states** - Always check for `updated`, `failed`, and `expired`.

5. **Don't call legacy confirm endpoints** - The TX State Machine replaces all `/confirm-tx`, `/set-pending-tx`, and `/sync` endpoints.
