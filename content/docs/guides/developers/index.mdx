# Build with Andamio

All guides use **preprod** (Cardano testnet) by default. See [API Integration](/docs/guides/developers/api-integration#ready-for-mainnet) when you're ready for production.

## Choose Your Path

| Path | Time | What You Get |
|------|------|--------------|
| **[Getting Started](/docs/getting-started)** | ~15 min | Full local dev environment with app template |
| **[API Quickstart](/docs/guides/developers/api-quickstart)** | ~5 min | First API call with curl (no app template) |

After setup, continue with **[Your First Andamio App](/docs/guides/developers/first-app)** to build something real.

## Guides

| Guide | Description |
|-------|-------------|
| [API Integration](/docs/guides/developers/api-integration) | Environment URLs, auth headers, making requests |
| [Authentication](/docs/guides/developers/authentication) | Wallet-based login, JWT flow, session management |
| [Transaction Handling](/docs/guides/developers/transactions) | Build → sign → submit lifecycle |
| [Error Handling](/docs/guides/developers/error-handling) | Recovery patterns for failed transactions |
