## Authentication

All API requests require authentication:

| Header | Purpose |
|--------|---------|
| `X-API-Key` | Application-level authentication |
| `Authorization: Bearer <jwt>` | User-level authentication (wallet signature) |

See [API Integration](/docs/guides/developers/api-integration#authentication) for details on obtaining and using these credentials.
