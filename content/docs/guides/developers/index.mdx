## Authentication

All API requests require two headers:

| Header | Purpose |
|--------|---------|
| `X-API-Key` | Application-level (your app) |
| `Authorization: Bearer <jwt>` | User-level (wallet signature) |

See [API Integration](/docs/guides/developers/api-integration#authentication) for the full auth flow.
