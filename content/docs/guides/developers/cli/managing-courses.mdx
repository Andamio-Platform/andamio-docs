# Managing Courses

## List Courses

```bash
andamio course list
```

To see only courses where you're a teacher:

```bash
andamio teacher courses
```

## Course Details

```bash
andamio course get <course-id>
```

## List Modules

```bash
andamio course modules <course-id>
```

Or use `--course` to specify by name instead of ID:

```bash
andamio course modules --course "Intro to Cardano"
```

The `--course` flag matches by substring. If multiple courses match, all candidates are listed with their IDs.

## View SLTs

```bash
andamio course slts <course-id> <module-code>
```

With `--course`:

```bash
andamio course slts <module-code> --course "Intro to Cardano"
```

This returns the Student Learning Targets for a specific module. The module must be on-chain (APPROVED or ON_CHAIN status) for this public endpoint to work.

## View Lesson Content

Get a single lesson by SLT index:

```bash
andamio course lesson <course-id> <module-code> <slt-index>
```

Get the module introduction:

```bash
andamio course intro <course-id> <module-code>
```

Get the module assignment:

```bash
andamio course assignment <course-id> <module-code>
```

## JSON Output

All commands support `-o json` for structured output:

```bash
andamio course modules <course-id> -o json | jq '.data[].content.course_module_code'
```

## Create a Module

Create a new module on an existing course, either from a compiled directory or explicit flags:

```bash
# From a compiled directory (reads title and code from outline.md)
andamio course create-module ./compiled/my-course/101 --course-id <id>

# From explicit flags
andamio course create-module --course-id <id> --code 101 --title "My Module"
```

Requires [user authentication](/docs/guides/developers/cli/authentication) (wallet login) and teacher access on the course.

## Course Owner Commands

If you own courses (created via on-chain transaction), manage them with the `course owner` subgroup. All require [user authentication](/docs/guides/developers/cli/authentication).

### List Your Courses

```bash
andamio course owner list
```

### Create a Course

```bash
andamio course owner create --title "My Course" --description "Learn things" --public
```

Optional flags: `--description`, `--image-url`, `--video-url`, `--category`, `--public`.

### Update Course Metadata

Only specified flags are updated — omitted fields remain unchanged:

```bash
andamio course owner update --course-id <id> --title "New Title"
andamio course owner update --course-id <id> --description "Updated" --public=false
```

### Register an On-Chain Course

After creating a course on-chain with `tx run`, register it with off-chain metadata:

```bash
andamio course owner register --course-id <id> --title "My Course"
```

### Manage Teachers

Set the teacher list for a course (repeatable `--teacher` flag):

```bash
andamio course owner teachers --course-id <id> --teacher addr1... --teacher addr2...
```

## Project Owner Commands

Manage projects you own. All require [user authentication](/docs/guides/developers/cli/authentication).

```bash
# List your projects
andamio project owner list

# Create a project
andamio project owner create --title "Community Dev" --description "Build things" --public

# Update project metadata (only changed flags sent)
andamio project owner update --project-id <id> --title "New Title"

# Register on-chain project with off-chain metadata
andamio project owner register --project-id <id>
```

## Your Dashboard

See a summary of everything you're enrolled in, teaching, and managing:

```bash
andamio user me
```

## Role-Specific Views

List courses where you're a teacher:

```bash
andamio teacher courses
```

List projects where you're a manager:

```bash
andamio manager projects
```

### Transactions

Build, sign, and submit transactions:

```bash
andamio tx build /v2/tx/global/user/access-token/mint --body '{"alias":"dev1",...}'
andamio tx sign --tx <unsigned-cbor> --skey ./payment.skey
andamio tx submit --tx <signed-cbor>
andamio tx status <tx-hash>
```

See [Transaction Signing](/docs/guides/developers/cli/transaction-signing) for the full workflow.
