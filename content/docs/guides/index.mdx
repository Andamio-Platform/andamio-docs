# Andamio Platform Guides

Welcome to the Andamio Platform guides! These guides help you get started with Andamio based on your role.

## Understand the Roles

Andamio uses six roles across two systems. See the [Roles Overview](/docs/guides/roles) for a complete breakdown.

| System | Roles |
|--------|-------|
| **Course** | Owner, Teacher, Student |
| **Project** | Owner, Manager, Contributor |

## Choose Your Guide

- **[Course Owner Guide](/docs/guides/courses)** — Create and manage courses, add teachers, control the course lifecycle
- **[Project Owner Guide](/docs/guides/projects)** — Set up collaborative projects, manage treasury and requirements
- **[Contributor & Student Guide](/docs/guides/contributors)** — Participate in courses and projects, earn verifiable credentials

## About Andamio

Andamio is a decentralized platform for credential-gated collaboration. It allows you to:

- Create educational courses and issue verifiable credentials
- Set up projects with credential requirements
- Build reputation through verifiable contributions
- Create transparent, auditable workflows
