# Andamio Platform Guides

Welcome to the Andamio Platform guides! These guides will help you get started with using Andamio, whether you're creating educational content, managing collaborative projects, or participating as a contributor.

## Getting Started

Choose the guide that matches your role:

- **[Course Creators](/docs/guides/courses)** - Learn how to create and manage courses on Andamio
- **[Project Creators](/docs/guides/projects)** - Set up and manage collaborative projects
- **[Contributors](/docs/guides/contributors)** - Participate in courses and projects, earn credentials

## About Andamio

Andamio is a decentralized platform for credential-gated collaboration. It allows you to:

- Create educational courses and issue verifiable credentials
- Set up projects with credential requirements
- Build reputation through verifiable contributions
- Create transparent, auditable workflows
