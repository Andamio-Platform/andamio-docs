# Setting Up Prerequisites

<Callout type="info">
This guide is under active development.
</Callout>

Prerequisites are the core of Andamio's credential-gated collaboration. A project requires contributors to hold specific credentials — earned by completing courses — before they can participate. No credential, no access to the task list.

Every project needs at least one course as a prerequisite. If you don't have a course yet, create one first.
