# Project Owner Guide

This guide will help you set up and manage collaborative projects on Andamio.

## What is a Project on Andamio?

Projects on Andamio enable credential-gated collaboration. You can set requirements for participation, manage contributor work, and distribute rewards transparently on-chain.
