# Contributor Guide

This guide will help you get started as a contributor on Andamio, whether you're taking courses or participating in projects.

## Getting Started with Andamio

As a contributor, you can:

- Earn credentials by completing courses
- Use credentials to access projects
- Build your on-chain reputation
- Earn rewards for project contributions

## Your First Steps

1. **Mint an Access Token** - Create your on-chain identity
2. **Enroll in Courses** - Start learning and earning credentials
3. **Join Projects** - Use your credentials to access collaborative work
4. **Build Reputation** - Complete tasks and earn verifiable credentials

## Key Workflows

| Workflow | Description |
|----------|-------------|
| Earn credentials | Enroll in courses, complete assignments, claim on-chain credentials |
| Complete prerequisites | Find a project's required credentials and complete the courses to earn them |
| Join projects | Commit to tasks, submit evidence, earn ADA rewards |
