# Andamio Protocol Documentation

Andamio is a protocol enabling distributed work across organizations of any size. Anyone can mint credentials on the Andamio Protocol. Contributors use these credentials to unlock new opportunities. Credentials can be shared across project teams, enabling the fluid movement of talented people among impactful teams.

## Example:

1. An organization needs a developer to help build some features for an app.
2. The organization mints a credential listing the required skills.
3. A contributor completes an assignment showing what they know and earns the credential. Along the way, they learn about the app, which helps them decide if they want to join the project.
4. The contributor uses the credential to join the app development project, complete tasks, and earn rewards.
5. The organization distirbutes rewards for completed work in a verifiable way, and can easily create reports showing the impact of funding.
6. When the project is done, the contributor can use the learning credential and contribution credentials to join other projects. Along the way, meeting other contributors and building relationships that might extend into new projects.

### All of this is possible with Andamio, and here is what's most important: 

Anyone can plug the tools of Andamio into any application, building new organizational tools, new social networks, and new ways to collaborate.

Andamio is a protocol for decentralized treasury management and contribution tracking that enables transparent project coordination on the Cardano blockchain. It provides tools for contributor onboarding, on-chain credentialing, permissionless reputation, and accountable fund allocation that empower teams to collaborate with high levels of transparency and trust.
