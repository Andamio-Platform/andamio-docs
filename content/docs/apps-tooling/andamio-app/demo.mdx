Andamio is an open protocol for credential-gated collaboration. Courses issue verifiable credentials. Projects gate access with those credentials. Everything is on-chain, auditable, and composable.

![Andamio Protocol Architecture — Global Primitives & Local States](/diagrams/andamio-architecture.png)

![Andamio Platform Stack](/diagrams/andamio-stack.png)

### What can you build?

- **Onboarding platforms** — structured learning paths with verifiable credentials
- **Treasury governance** — credential-gated access to shared funds
- **Coordination infrastructure** — for guilds, collectives, and DAOs
- **Agent workflows** — CLI composability means AI agents can build on the protocol too
