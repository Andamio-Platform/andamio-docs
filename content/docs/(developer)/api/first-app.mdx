Create a course, add a module, and enroll as a student by committing to an assignment, all on preprod.

**Time**: ~30 minutes. **Prerequisite**: [Getting Started](/docs/api/getting-started).

<Callout type="info">
**Start from the template**: Clone the [andamio-app-template](https://github.com/Andamio-Platform/andamio-app-template) to follow along. It includes production-ready hooks for transaction handling — see the [How Transactions Work](https://github.com/Andamio-Platform/andamio-app-template#how-transactions-work) section for details.
</Callout>

## Step 1: Understand the Transaction Flow

Every action in Andamio follows the same pattern:

```
Your App → Gateway (build) → Wallet (sign) → Gateway (submit) → Cardano
```

1. **Build**: Your app requests a transaction from the Gateway
2. **Sign**: The user signs with their wallet
3. **Submit**: The signed transaction goes back to the Gateway
4. **Confirm**: The Gateway submits to Cardano and tracks confirmation

---

## Step 2: Create a Course

Open your [app template](https://github.com/Andamio-Platform/andamio-app-template) at `localhost:3000` and navigate to the course creation page.

<Callout type="info">
If you don't see course creation options, your Access Token may not have course creator permissions. On preprod, you can grant yourself permissions — see [Course Creator Setup](#course-creator-setup) below.
</Callout>

### What happens on-chain

When you create a course, Andamio:
- Mints a **Course Token** representing your course
- Creates a **Course State UTxO** holding course metadata
- Links your Access Token as the course creator

This is your first real transaction. Watch the confirmation — it takes about 20 seconds on preprod.

---

## Step 3: Add a Module

Courses contain modules. Each module can have:
- Learning content (off-chain, referenced by hash)
- Assignments (on-chain commitments)

Add a simple module to your course. The module metadata lives off-chain, but the module's existence is recorded on-chain.

---

## Step 4: Commit to an Assignment

Now switch perspectives. Using a different wallet (or the same one on a test course), commit to the assignment in your module as a student. There is no separate enrollment step. Your first commitment enrolls you in the course.

### What happens on-chain

The commitment transaction:
- Mints your **course-state token**, named after your Access Token alias
- Creates a UTxO holding that token, a refundable deposit and your commitment
- Records the course in your global state

You are now enrolled in the course.

You now have an on-chain relationship with the course.

---

## Step 5: Get Assessed

Your commitment carries a hash of your evidence. The evidence itself stays off-chain.

1. You can replace your evidence with a second transaction
2. A course teacher assesses the commitment and accepts or refuses it
3. Once it is accepted, you can claim the credential

---

## Summary

| Action | On-chain Result |
|--------|-----------------|
| Create course | Course Token + Course State UTxO |
| Add module | Module reference in course state |
| Commit to assignment | Course-state token + a UTxO holding the commitment |
| Update evidence | Same UTxO, new evidence hash |

Every interaction follows the same build → sign → submit pattern. The Gateway handles transaction construction; your app handles UX.

## Appendix: Course Creator Setup

On preprod, you can grant course creator permissions to your Access Token:

1. Go to [preprod.app.andamio.io](https://preprod.app.andamio.io)
2. Connect your wallet
3. Navigate to Admin → Permissions
4. Add your Access Token as a course creator

This is a preprod convenience — on mainnet, permissions are managed by instance administrators.
