The Andamio API uses tiered pricing. Each tier determines your rate limits, monthly quota, and maximum number of API keys.

## Pricing Tiers

| Tier | Price | Monthly Requests | Daily Limit | Per-Minute | Per-Second | Max Keys |
|------|-------|-----------------|-------------|------------|------------|----------|
| **Free** | $0 | 15,000 | 500 | 20 | 20 | 1 |
| **Starter** | $29/mo | 75,000 | 2,500 | 50 | 50 | 2 |
| **Growth** | $129/mo | 750,000 | 25,000 | 500 | 500 | 5 |
| **Enterprise** | Custom | 999,999+ | 100,000 | 2,000 | 2,000 | Unlimited |

Start with Free for development and testing. Upgrade when you need higher limits.

## Quota Headers

This section covers the Andamio API, called with a developer key. Each request that counts against your developer quota returns what is left in its response headers:

| Header | Description |
|--------|-------------|
| `X-Quota-Remaining-Monthly` | Requests left this month, after this one |
| `X-Quota-Reset-Monthly` | When the monthly quota resets, as an RFC 3339 timestamp (the start of next month, UTC) |
| `X-Quota-Remaining-Daily` | Requests left today, after this one |
| `X-Quota-Reset-Daily` | When the daily quota resets, as an RFC 3339 timestamp |

No header reports the per-second or per-minute limits.

When you exceed a limit, the API returns `429 Too Many Requests`. A 429 carries none of these headers, and its body is `{ "error": "<message>" }` rather than the error envelope. The message names the limit you hit: per second, per minute, daily or monthly. After a per-second or per-minute 429, back off and retry within the minute. After a daily or monthly 429, wait until the reset time from your last successful response.

Andamio Issuer keeps its own quota and returns `402 QUOTA_EXHAUSTED` when it runs out. See [Andamio Issuer API integration](/docs/issuer/integrate).

## View Available Plans

List current pricing tiers (no authentication required):

```bash
curl https://preprod.api.andamio.io/api/v2/billing/plans
```

## Subscription Management

Manage your subscription through Stripe-hosted pages:

### Start or Upgrade Subscription

```bash
curl -X POST https://preprod.api.andamio.io/api/v2/billing/checkout \
  -H "X-API-Key: $API_KEY" \
  -H "Authorization: Bearer $DEV_JWT" \
  -H "Content-Type: application/json" \
  -d '{"tier": "starter"}'
```

Returns a URL to Stripe Checkout. After completing payment, you're redirected back to your app.

### Manage Existing Subscription

```bash
curl -X POST https://preprod.api.andamio.io/api/v2/billing/portal \
  -H "X-API-Key: $API_KEY" \
  -H "Authorization: Bearer $DEV_JWT"
```

Returns a URL to the Stripe Customer Portal where you can update payment methods, change plans, or cancel.

### Check Subscription Status

```bash
curl https://preprod.api.andamio.io/api/v2/billing/status \
  -H "X-API-Key: $API_KEY" \
  -H "Authorization: Bearer $DEV_JWT"
```

### Subscription States

| Status | Meaning |
|--------|---------|
| `active` | Subscription is current and paid |
| `active` + `cancel_at_period_end` | Active but will cancel at period end |
| `past_due` | Payment failed — retrying |
| `canceled` | Subscription ended |
| `trialing` | In trial period |
| `incomplete` | Initial payment pending |
| `paused` | Subscription paused |

## Billing Endpoints

| Method | Endpoint | Auth Required | Description |
|--------|----------|--------------|-------------|
| `GET` | `/v2/billing/plans` | None | List available tiers (public) |
| `POST` | `/v2/billing/checkout` | API Key + Developer JWT | Create Stripe checkout session |
| `POST` | `/v2/billing/portal` | API Key + Developer JWT | Create Stripe customer portal |
| `GET` | `/v2/billing/status` | API Key + Developer JWT | Check subscription status |
