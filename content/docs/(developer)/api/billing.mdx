The Andamio API uses tiered pricing. Each tier determines your rate limits, monthly quota, and maximum number of API keys.

## Pricing Tiers

| Tier | Price | Monthly Requests | Daily Limit | Per-Minute | Per-Second | Max Keys |
|------|-------|-----------------|-------------|------------|------------|----------|
| **Free** | $0 | 15,000 | 500 | 20 | 20 | 1 |
| **Starter** | $29/mo | 75,000 | 2,500 | 50 | 50 | 2 |
| **Growth** | $129/mo | 750,000 | 25,000 | 500 | 500 | 5 |
| **Enterprise** | Custom | 999,999+ | 100,000 | 2,000 | 2,000 | Unlimited |

Start with Free for development and testing. Upgrade when you need higher limits.

## How Limits Work

Limits belong to your developer account, not to a key. Every key on the account draws on the same counts.

The API checks four limits on every request made with a developer key:

- **Per minute and per second.** Each is a fixed window that starts with your first request after the last window ended. It does not slide.
- **Daily.** Resets at 00:00 UTC.
- **Monthly.** Resets on the 1st of the month at 00:00 UTC.

The per-second limit equals the per-minute limit on every tier, so in practice the per-minute limit is the one you reach.

### What Counts

- **Every request made with a developer key counts** once against each limit when it arrives, before the API handles it. A request that then fails, for example with `400`, `404` or `502`, still counts.
- **A request refused with `401`** (a missing or invalid key) counts against nothing.
- **A request refused with `429`** does not count against the daily or monthly quota. It does count inside the per-minute and per-second windows, so retrying at once keeps you refused until the window ends.
- **A request that needs no key,** such as `GET /v2/billing/plans`, counts against nothing.
- **You are not charged per request.** Your tier is a monthly subscription. A request over a limit is refused, not billed.

## Quota Headers

This section covers the Andamio API, called with a developer key. Each request that counts against your developer quota returns what is left in its response headers:

| Header | Description |
|--------|-------------|
| `X-Quota-Remaining-Monthly` | Requests left this month, after this one |
| `X-Quota-Reset-Monthly` | When the monthly quota resets, as an RFC 3339 timestamp (the start of next month, UTC) |
| `X-Quota-Remaining-Daily` | Requests left today, after this one |
| `X-Quota-Reset-Daily` | When the daily quota resets, as an RFC 3339 timestamp |

No header reports the per-second or per-minute limits.

## When You Hit a Limit

The API answers `429 Too Many Requests`. The body is `{ "error": "<message>" }`, where `error` is a string, not the error envelope other errors use. The message names the limit:

| Message | Limit | What to do |
|---------|-------|------------|
| `Too many requests (minute limit)` | Per minute | Wait for the minute window to end, up to 60 seconds, then retry |
| `Too many requests (second limit)` | Per second | Wait a second, then retry |
| `Daily quota exceeded` | Daily | Wait until the `X-Quota-Reset-Daily` time from your last successful response, or upgrade |
| `Monthly quota exceeded` | Monthly | Wait until the `X-Quota-Reset-Monthly` time from your last successful response, or upgrade |

A `429` carries no `Retry-After` header and no quota headers. Pace bulk work to stay under your per-minute limit, and never retry a refused request at once.

Andamio Issuer keeps its own quota and returns `402 QUOTA_EXHAUSTED` when it runs out. See [Andamio Issuer API integration](/docs/issuer/integrate).

## View Available Plans

List current pricing tiers (no authentication required):

```bash
curl https://preprod.api.andamio.io/api/v2/billing/plans
```

## Subscription Management

Manage your subscription through Stripe-hosted pages:

### Start or Upgrade Subscription

```bash
curl -X POST https://preprod.api.andamio.io/api/v2/billing/checkout \
  -H "X-API-Key: $API_KEY" \
  -H "Authorization: Bearer $DEV_JWT" \
  -H "Content-Type: application/json" \
  -d '{"tier": "starter"}'
```

Returns a URL to Stripe Checkout. After completing payment, you're redirected back to your app.

### Manage Existing Subscription

```bash
curl -X POST https://preprod.api.andamio.io/api/v2/billing/portal \
  -H "X-API-Key: $API_KEY" \
  -H "Authorization: Bearer $DEV_JWT"
```

Returns a URL to the Stripe Customer Portal where you can update payment methods, change plans, or cancel.

### Check Subscription Status

```bash
curl https://preprod.api.andamio.io/api/v2/billing/status \
  -H "X-API-Key: $API_KEY" \
  -H "Authorization: Bearer $DEV_JWT"
```

### Subscription States

| Status | Meaning |
|--------|---------|
| `active` | Subscription is current and paid |
| `active` + `cancel_at_period_end` | Active but will cancel at period end |
| `past_due` | Payment failed — retrying |
| `canceled` | Subscription ended |
| `trialing` | In trial period |
| `incomplete` | Initial payment pending |
| `paused` | Subscription paused |
