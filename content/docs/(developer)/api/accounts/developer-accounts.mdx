A developer account holds your API keys and your billing tier. You create it and manage it in the developer portal at [app.andamio.io/api-setup](https://app.andamio.io/api-setup). The public Andamio API has no routes for developer registration, developer login or key management.

## Keys and Tokens

Your app sends two things to the Andamio API. Your developer account is what gets you the first one.

| What | What it identifies | How to get it | Header |
|------|--------------------|---------------|--------|
| **API key** | Your application | Generate it in the [developer portal](https://app.andamio.io/api-setup) ([API Keys](/docs/api/accounts/api-keys)) | `X-API-Key` |
| **User login token** (User JWT) | The user acting | The user signs a wallet challenge ([Authentication](/docs/api/accounts/authentication)) | `Authorization: Bearer` |

Authenticated requests need the API key. Requests that act for a user also need that user's login token.

The developer portal signs you in with its own developer login token. That token is for the portal only. Your app never needs it, and no route on the public API accepts it.

## Register in the Developer Portal

Developer registration happens on the **mainnet** app, so you need a mainnet Access Token first. The [Quickstart](/docs/api/getting-started) walks through each step.

1. Mint a mainnet Access Token at [app.andamio.io](https://app.andamio.io).
2. Go to [app.andamio.io/api-setup](https://app.andamio.io/api-setup) and connect the wallet that holds it.
3. Register as a developer with your email address, and sign with your wallet.
4. Open the verification link the portal emails you. You must verify your email before you can create an API key.
5. Generate your first API key.

The portal manages keys for every environment, preprod included. `/api-setup` on the preprod app redirects to the dashboard by design.
