title: API Keys

Authenticated requests to the Andamio API require an API key in the `X-API-Key` header. Your API key identifies your application and sets your rate limits and quotas.

## The Developer Portal

The developer portal at [app.andamio.io/api-setup](https://app.andamio.io/api-setup) is the only place to get and manage API keys. The public Andamio API has no routes for creating, listing or deleting keys.

The portal lives on the **mainnet** app only and manages keys for every environment through its network selector. `/api-setup` on the preprod app redirects to the dashboard by design. See the [Quickstart](/docs/api/getting-started) for the full flow.

<Callout type="info" title="Preprod keys are open to everyone">
Self-serve **preprod** key generation is open to all registered developers as of API v2.4.1 (July 2026). If you previously hit a 403 generating a preprod key, retry. The internal-testers gate has been removed.
</Callout>

## Create a Key

Before you create a key:

1. [Register a developer account](/docs/api/accounts/developer-accounts) in the portal
2. Verify your email address

Then, in the portal:

1. Select the network for the key: **preprod** for development, **mainnet** for production
2. Click **Generate API Key** and name it
3. Copy the key and store it securely

<Callout type="warn" title="Save your key">
The portal shows the key once. Copy it immediately.
</Callout>

The number of keys you can hold depends on your [billing tier](/docs/api/billing).

## Rotate a Key

To rotate a key, create a new key in the portal, move your app to it, then delete the old key.

## Delete a Key

Delete a key in the portal. Deletion cannot be undone, and the deleted key stops working.
