Client libraries for building applications on the Andamio Protocol.

## Packages

| Package | Description | Install |
|---------|-------------|---------|
| [@andamio/transactions](/docs/sdk/npm-packages/andamio-transactions) | Build and submit Andamio Protocol transactions | `npm install @andamio/transactions` |

## When to Use the SDK vs the CLI vs the API

| Approach | Best for |
|----------|----------|
| **SDK** | Building custom frontends and dApps that interact with the Andamio Protocol |
| **[CLI](/docs/guides/developers/cli)** | Managing courses and tasks from the terminal, scripting, agent workflows |
| **[API](/docs/guides/developers/api-quickstart)** | Direct HTTP integration from any language or platform |

The SDK wraps the on-chain transaction logic. The CLI wraps the API. The API sits between both and the Cardano ledger.
