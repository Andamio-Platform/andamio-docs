# ls-project

Project system validators that power collaborative work on Andamio.

**GitHub**: [Andamio-Platform/ls-project](https://github.com/Andamio-Platform/ls-project)

## Overview

This repository contains validators for the Project application protocol, including:

- Contributor state validators
- Treasury validators
- Escrow validators
- Project-specific token policies
