Course system validators that power learning and credentialing on Andamio.

**GitHub**: [Andamio-Platform/ls-course](https://github.com/Andamio-Platform/ls-course)

## Overview

This repository contains validators for the Course application protocol, including:

- Course state validators
- Assignment validators
- Module validators
- Course-specific token policies
