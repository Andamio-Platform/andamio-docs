# plumbline-global-state

Global state validators and policies that form the foundation of the Andamio Protocol.

**GitHub**: [Andamio-Platform/plumbline-global-state](https://github.com/Andamio-Platform/plumbline-global-state)

## Overview

This repository contains the core global state management validators for the Andamio Protocol, including:

- Global state validator
- Index validators
- Access token policies
- Parameter reference validators
