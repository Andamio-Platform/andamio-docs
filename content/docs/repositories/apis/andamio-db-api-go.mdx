The database API service that manages off-chain data for the Andamio Platform.

**GitHub**: [Andamio-Platform/andamio-db-api-go](https://github.com/Andamio-Platform/andamio-db-api-go)

## Overview

This Go-based service provides:

- User profile and account management
- Course and project metadata storage
- Off-chain state synchronization
- Database operations for platform services

## Related Repositories

- [andamio-api](/docs/repositories/apis/andamio-api) - API Gateway that routes to this service

## Getting Started

```bash
git clone https://github.com/Andamio-Platform/andamio-db-api-go.git
```

See the repository README for setup and configuration instructions.

<Callout type="info">
This repository replaces the deprecated TypeScript-based `andamio-db-api` repository.
</Callout>
