# andamioscan

An indexer service that queries and aggregates on-chain Andamio Protocol data.

**GitHub**: [Andamio-Platform/andamioscan](https://github.com/Andamio-Platform/andamioscan)

## Overview

Andamioscan provides:

- Real-time indexing of Andamio Protocol transactions
- Query APIs for courses, students, and transactions
- Transaction history and statistics
- Cross-reference data for protocol analysis
