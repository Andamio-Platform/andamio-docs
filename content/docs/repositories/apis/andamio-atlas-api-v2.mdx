The transaction builder API that constructs Cardano transactions for Andamio Protocol operations.

**GitHub**: [Andamio-Platform/andamio-atlas-api-v2](https://github.com/Andamio-Platform/andamio-atlas-api-v2)

## Overview

This API provides:

- Transaction building for all Andamio Protocol operations
- CBOR-encoded transaction outputs
- Cost estimation for protocol transactions
- Support for V2 protocol validators
