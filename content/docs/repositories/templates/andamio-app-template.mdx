# andamio-app-template

The official starter template for building applications on the Andamio Protocol.

**GitHub**: [Andamio-Platform/andamio-app-template](https://github.com/Andamio-Platform/andamio-app-template)

## Overview

- Next.js with App Router
- Pre-configured Andamio Gateway integration
- Wallet connection (Eternl, Lace, Nami)
- Transaction signing flow
- Tailwind CSS

## Quick Start

```bash
git clone https://github.com/Andamio-Platform/andamio-app-template.git
cd andamio-app-template
npm install
```

See **[Getting Started](/docs/getting-started)** for complete setup — API key generation, environment configuration, and verification steps.
