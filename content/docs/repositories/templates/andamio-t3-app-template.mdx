# andamio-t3-app-template

A starter template for building applications on the Andamio Platform using the T3 stack.

**GitHub**: [Andamio-Platform/andamio-t3-app-template](https://github.com/Andamio-Platform/andamio-t3-app-template)

## Overview

This template provides:

- Next.js with App Router
- tRPC for type-safe APIs
- Prisma for database management
- Tailwind CSS for styling
- Pre-configured Andamio SDK integration

## Getting Started

```bash
git clone https://github.com/Andamio-Platform/andamio-t3-app-template.git
cd andamio-t3-app-template
npm install
```

See the [Andamio Pioneers Getting Started Guide](/docs/pioneers/getting-started) for detailed setup instructions.
