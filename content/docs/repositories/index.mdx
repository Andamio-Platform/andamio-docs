This page provides an overview of the key Andamio Platform repositories. All repositories are hosted on GitHub under the [Andamio-Platform](https://github.com/Andamio-Platform) organization.

## On-Chain Code

Smart contracts and validators that power the Andamio Protocol.

| Repository | Description |
|------------|-------------|
| [plumbline-global-state](/docs/repositories/on-chain/plumbline-global-state) | Global state validators and policies |
| [access-token](/docs/repositories/on-chain/access-token) | Access token policy and validators |
| [ls-course](/docs/repositories/on-chain/ls-course) | Course system validators |
| [ls-project](/docs/repositories/on-chain/ls-project) | Project system validators |
| [ls-instance](/docs/repositories/on-chain/ls-instance) | Instance system validators |

## APIs

Backend services that interact with the Andamio Protocol.

| Repository | Description |
|------------|-------------|
| [andamio-api](/docs/repositories/apis/andamio-api) | Main API Gateway service |
| [andamioscan](/docs/repositories/apis/andamioscan) | On-chain data indexer |
| [andamio-atlas-api-v2](/docs/repositories/apis/andamio-atlas-api-v2) | Transaction builder API |
| [andamio-db-api-go](/docs/repositories/apis/andamio-db-api-go) | Database API (Go) |
