# andamio-docs

The source code for this documentation site.

**GitHub**: [Andamio-Platform/andamio-docs](https://github.com/Andamio-Platform/andamio-docs)

## Overview

This repository contains:

- Protocol documentation
- API reference documentation
- Whitepaper and tokenomics
- Guides and tutorials
- Interactive API documentation

## Tech Stack

- Next.js with App Router
- Fumadocs for documentation framework
- MDX for content
- OpenAPI integration for API docs

## Contributing

We welcome contributions to improve the documentation:

1. Fork the repository
2. Make your changes
3. Submit a pull request

## Getting Started

```bash
git clone https://github.com/Andamio-Platform/andamio-docs.git
cd andamio-docs
npm install
npm run dev
```

The development server will start at `http://localhost:3000`.
