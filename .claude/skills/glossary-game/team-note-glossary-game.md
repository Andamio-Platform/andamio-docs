# Team Note: Glossary Game

The **Concept Validation Game** (aka Glossary Game) is now available as a collaborative learning tool for refining Claude's understanding of Andamio terminology.

## Quick Start
Just say: *"Let's run an example with [term]"* or *"Let's play the Glossary Game"*

## How It Works
1. **Claude presents** current understanding of a term
2. **Team member validates/corrects** with feedback
3. **Claude updates** understanding and documentation
4. **Iterate** until understanding is solid

## Benefits
- Catches and fixes Claude's misconceptions about our terminology
- Creates accurate, team-validated definitions in real-time
- Builds Claude's contextual knowledge of Andamio-specific meanings
- Updates our working glossary (`docs/reference/GLOSSARY.md`) as we go

## Best Use Cases
- When Claude seems confused about a term
- Before working on new protocol areas
- When inconsistent terminology usage is noticed
- During onboarding of new concepts

The game is designed to be quick, iterative, and immediately useful for improving Claude's effectiveness on our documentation and development tasks.
